# V42 — 実測の崖と砂浜を北へつなぐ

東京都の25cm格子を北隣の09QC1701へ拡張し、09QC1711と約400×600mの一続きの実測地形にした。海側から見た時に細かな崖脚が急に粗い地形へ切り替わる位置を遠ざけ、北側の浜から入水できる範囲を増やした。

384万の元標本を同じ座標格子で連結。境目の高さを平均化せず、元の斜面を保持する。247描画区画、7,672,002三角形。元標本に対する局所座標と標高格納の最大数値誤差は約8.29mmで、現地の測量精度や現在の浜との一致ではない。[出典と再現方法](niijima-native-survey.md)。

## 確認したこと

- 元の両ZIP/TIFFのSHA256、投影・格子・座標を検査し、配布データから生成ファイルの再現を照合した。
- 実測格子・描画と床・水深範囲・島間の経路に関わる42テストが通過。今回の変更に対する確認であり、前版の全374テストを再実行したという意味ではない。
- 型検査、Viteと単体HTMLのビルドが通過。
- 北側の浜から通常のcontrollerへ65秒間入力し、歩行→水泳→潜水→浮上→上陸を確認。402サンプル、終了時接地、目の高さは地面から1.64m。開始地点は開発用QAで配置し、OSの物理キーによる一連の旅とは区別する。
- 内蔵ブラウザの単体HTMLで384万標本が標準で有効、開発QAなし、外部素材要求0、console error0を確認。静的HTTPでの実行で、file://は未確認。
- 海岸沿い・海上遠景の新旧画像と実写真を独立レビュー。崖脚の細部が連続する範囲は広がり、新しい穴・切断・巨大な水の尖りは2視点では見られないため、限定改善として採用。

## 残る差

測定範囲のさらに外側には地形密度の切り替わりが残る。崖の灰色の均一な材質と大きい影、平たい泡は実景との差が大きい。全海岸の実測化、動的な侵食と漂砂、全体の実写品質は未達。
