# Shore solver v10 candidate

Opt-in depth-integrated finite-volume shallow-water candidate. This is a first-order hydrostatic reconstruction/Rusanov operator on a fixed world grid; it propagates finite-depth disturbances and nonlinear compressive bores. It cannot represent overturning barrels, vertical water sheets, air entrainment or CFD. Foam is an advected compression concentration proxy.

## Integration

Construct `ShoreSolver(renderer)`, bind existing bathymetry/FFT shared uniform objects once, call `update(deltaSeconds,cameraX,cameraZ)` after FFT evolution and before height-cache/render passes. Bind solver.uniforms into each sampling consumer. Include `shoreSolverSampling` after `shoreWaveSampling`, then apply `shoreSolvedSurface(world,fallbackHeight,fallbackFoam)` consistently. `createShoreSolverUniforms()` supplies fresh ready=0 fallbacks to optional consumers. Terrain sampler declarations remain the consumer's existing declarations; helper does not duplicate `uBathyTriangulated`.

128² RGBA16F ping-pong targets default to 192 m (1.5 m cells). State is water depth, x/z depth-integrated momentum and foam. Terrain is borrowed, never replaced. GPU state uses nearest sampling; display reconstructs bilinear **world free-surface elevation** from four cell-center terrain+depth samples to avoid depth interpolation producing bed-shaped steps. Solver is applicable only to the selected Niijima coastal candidate at root integration; helper excludes shelter <.18, deep water >=11 m, domain edges and dry cells. Bathymetry remains existing procedural/scanned input, not a new survey.

Camera shifts snap to integer cells and reproject conserved state from the old world bounds; newly exposed cells initialize from the current FFT. Fully nonoverlapping camera jumps reset via new-cell initialization. Call reset after changing terrain/environment to discard incompatible history. No autonomous sine forcing: prescribed FFT height and uphill characteristic momentum supply the open boundary, with a six-cell sponge. This is approximate one-way boundary forcing, not a two-way coupling or wave-spectrum direction reconstruction.

Hydrostatic face reconstruction and pressure correction preserve lake at rest even at wet/dry transitions. A conservative 2D CFL bound uses enforced maximum depth and vector velocity; at most eight passes run per frame, discarding excess wall time rather than violating CFL. Diagnostics expose `stableDelta`, `substeps`, `simulationElapsed`, `droppedSeconds`. Depth is capped at maxDepth+maxHeight, velocity is capped, friction removes momentum, and boundary sponge exchanges water. These safety caps and forcing mean full-domain water conservation is not claimed. Computational bed is floored at -12 m outside the active shallow-water display domain, an offshore truncation whose reflected waves must be checked visually. Long frame drops slow the simulation relative to FFT forcing; droppedSeconds makes this observable.
