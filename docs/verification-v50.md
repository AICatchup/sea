# V50 — 大きな白い塗り面から、分岐する泡へ

浅瀬の泡が大きな均一の白い島に見える状態を改善した。波・浅水計算・発生・輸送は保ち、計算された泡の値を画面上の被覆へ変換する方法と、その内側の光学的な細部を変更した。`foamstructure=0`で従来版を比較できる。

## 実景と原因

[新島観光案内所の写真](https://niijima-info.jp/column/4724/)の地上目線・海側斜めを再確認し、[Tokyo Nature Drift](https://www.youtube.com/watch?v=Nwf2TvqiY5g)の70〜75秒付近などを内蔵ブラウザで再生・フレーム送りした。浜の濡れた帯、砂の疎密、背景の砕波帯を参照した。選択した場面の確認で、全編の波周期・波高・泡径の測定ではない。自動字幕は場所の検索補助に留める。参考映像・写真の画素はゲームや公開証拠へ転載しない。

同じ凍結した波でpoolを消しても白い島が残り、surface foamも消すと消えた。主な対象は水面shaderだった。従来は閾値化して1になった被覆を気泡の濃度にも使っており、実際の値が0.42でも内部の透過孔を閉じていた。新しい材質には閾値化前の値を渡す。

最初の丸い孔の案は水玉に見えるため不採用。内部だけの修正も限定的だった。採用候補は、不規則に歪ませた複数の尺度を使って白い塊を分岐させ、小さな気泡の縁には光の向きに沿う明暗を付ける。未解像の細部は平均へ移り、遠方で孔が閉じ切ったり細かな点がちらつくのを抑える。

## 見た目の量と物理量を区別する

計算上の波高・流量・泡の発生/移流は変更していないが、**見える白い面積と明るさは増える**。同一画像の泡非表示版との差をsRGB値への重み付きRGBで集計すると、近景/沿岸/高めの3視点で画面平均の差は約0.0301/0.00675/0.00511（0〜1）。旧版の正の明度寄与に対して約3.91/36.41/5.24倍で、沿岸は旧寄与が極めて小さい。これを泡の体積やエネルギーの保存と呼ばない。

2つの被覆帯を掛けた数学関数は、独立・一様な入力では元の値に近い平均へなる。しかし実shaderは変換したnoiseを使い、材質にも同じfieldを再使用する。そのため、実景の画素被覆率が物理的な濃度と等しい証明ではない。寸法、陰影、孔、微細模様の移動は制作上の近似で、個別の気泡・巻き込み流体を計算したものではない。

## 検証

コード`7b935a7c1af84e1e46d1e550283584bf3175a9a5`で全425テスト、型検査、Vite・単体HTML生成が成功。CPUテストは飽和した被覆との混同、空の水、上限・下限、独立一様な分布の期待値、未解像時の平均への収束を確認する。

実GPUの7つの光学fixtureは全て有限。旧版では被覆1/濃度0.42の不透明度が全標本1になったが、修正後はばらつきが残る。濃度1でも小さな孔と明暗を残し、未解像の位置をずらしても平均が変わらない。空の水に泡の寄与を加えない。fixtureは材質関数の範囲・遠方の安定性を確認するもので、実海域の濃度校正ではない。

近景・沿岸・高めの3視点で、同一のカメラ/FFT/浅水状態/粒子/照明を固定し、旧→新→旧を比較。旧へ戻すと全画素一致、surface/pool双方を消した旧/新も全画素一致。浅水readbackの統計も同一。各30フレームの平均間隔は約18.0〜18.5msで、GPU専用タイマーではない。

水中の初回比較には手の姿勢補間による差があり、左下の手だけで1,678画素が変化した。検証時だけ手を隠して再比較すると、水中の旧→新→旧は全画素一致。手の表示は復元し、製品の体を隠して仕上げたことにはしていない。

最終単体HTTP版は開発QAなし、新しいshaderの存在を読み戻した。通常キーリスナーへの合成DOM入力で砂浜→約20m先の浅瀬→元の浜を往復。272標本、接地したwalkへ復帰、目と床の差1.64m。1,484フレームの平均18.32ms、p95 18.70ms（録画負荷を含む）。外部素材要求0、今回の読み込み以降のconsole error 0。OS入力や全航路・泳ぎ/潜水の証明ではない。

同じ実行のcanvasを録画し、27.333秒・1280×720・821フレームのMP4として全フレームをデコード。抽出した始め/中程/終わりを実見し、内蔵ブラウザで終端到達も確認した。[検証用動画](checks/v50/verification-motion.mp4)。完全な人間の聴感・動作受入や、全体完成後に制作する紹介動画ではない。

独立したGPT-6.1 Sol / lowが6枚と2枚の実景・コードを確認し、局所改善として条件付き採用。円孔の規則性と巨大な白面は減ったが、白片の平面感・伸びた先端、巻き込み・厚み・飛沫・砕ける過程の立体性は残る。根拠は[checks/v50](checks/v50)。

## 残る要求

次の大きな差は、泡の模様だけでなく砕ける波の立体形状と時間的な連続、実景に沿う崖・浜の全域の形状/材質。漂砂・侵食・堆積、全島の航海・人体・船・音の受入、実写同等、1cmの現地一致、最終紹介動画は未達。今回の検証を全体完成に読み替えない。
