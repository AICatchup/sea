# V114: 波の継続供給と、小さな立体の泡

2026-10-25。新島・シークレットの砕波、接合、白水を改修した記録。

[音付きMP4](checks/v114/wave-lifecycle.mp4) · [再生ページ](checks/v114/review.html) · [前版V113](breaking-wave-status-v113.md)

## 変更

- **最初の着水で波全体を止めない。** 先端が着水すると、その後ろの水の放出まで終えていた。波頭が支えている間は供給を続け、各時刻に放出された水が個別に落下・着水する。前面の支持を失う、波頭が下がる、または供給時間の上限に達すると供給を終える。時間上限は描画用の近似であり、厳密な流体計算ではない。
- **接合中の水を早く消さない。** 描画では120msの接合補正を受ける新しい水を、補正前の着水判定が不可逆に削除する場合があった。接合区間と判定を整合させる。実際に水面を離れた水の再着水は従来どおり吸収し、海面が下がっても復活させない。
- **白水を大きな外殻で描かない。** 半透明の外殻と、丸い層の試作は近接映像で薄い破片や山のように見えたため採用しなかった。最終版は1群あたり32個の小さな立体の泡を使う。640三角形で、旧外殻の720三角形を下回る。着水量を同じ群れへ補給し、流れに運ばれながら広がり、厚み・濃度を失って消える。背景の泡は既存の輸送場に残る。
- **先端の水量も統一。** 初回着水だけ別の大きな塊を出す処理を廃し、先端も1つの放出時間区間の水量として扱う。既存水面の高さへさらに大きな波を足さないよう、上に加える泡の層には厚み上限を設ける。
- **同じ波への面の重ね合わせを防ぐ。** 時間だけで再生成を許す判定に加え、移動中の波面がまだ所有している範囲を調べる。
- **反射の境界を合わせる。** 浅水計算で失われる短い重力波の傾きを補い、巻いた面では高さ方向にも微小な傾きを与える。大波を浅瀬で制限する係数を小波にも使うと、風のある浅瀬が鏡のようになるため、小波自身の高さで制限する方式へ分離した。基礎水面と巻き込み面の接合付近では反射に使う傾きを合わせる。平面反射の空を曲面へ投影する旧方式には戻していない。
- **泡の石状の陰影と輪郭を減らす。** 近接映像で見えた小さな硬い塊に対し、縁の光路長に応じた透過と、泡の多重散乱を近似する照明を加えた。三角形数は増やしていない。

この砕波を通常のゲームで有効にした。比較目的では `breakinglips=0` で切り離せる。旧密度積分の試作 `frothvolume=1` は既定では使用しない。

## 検証と保存

最終回帰テスト94件、TypeScript、製品ビルド、単独HTMLの生成を確認。移動する解析波に対して、先端着水後も供給が続くこと、接合中の早期削除、泡の補給・拡散・減衰・消滅、有限の寿命を検査した。追加の2件では、大波が制限される浅瀬でも小波が残ること、水際で連続的に弱まることを検査した。解析波は新島の実測データではない。

Chromeの実際のゲーム描画を最大1/60秒の計算刻みで進め、24fps・433フレームとして保存する。フレーム補間や生成映像を加えない。音声は同じゲームの音声グラフを映像の時刻で合成した48kHzステレオで、実際の海の録音ではない。固定刻みの映像は実時間FPSの証拠にはしない。

物理の計算点や描画解像度を減らす代わりに、水の放出履歴の検索を二分探索へ変更し、まだ存在しない水の履歴計算を省いた。履歴10万回の比較で出力差は0だった。ただし描画全体の高速化率は未測定で、反射用の追加サンプルには負荷もある。

再現用URL: `/?capture=1&view=secret-north&waverecord=1`。この開発用画面は収録操作まで物理を停止し、通常のゲームには遠隔移動UIを追加しない。

通常の保存はブラウザのダウンロードを使う。システムドライブの容量が少ない場合、`python scripts/qa-recording-server.py <既存の保存フォルダー>` を明示的に起動し、URLへ `capturestore=1` を付けると別ドライブへ直接保存できる。ローカルのViteプレビューからのみ受け付け、既存ファイルを上書きしない。確認後は保存サーバーを終了する。

動画化: `python scripts/render-wave-recording.py <収録JSON> <新規出力フォルダー>`。10fpsの旧記録にも対応する。

Chromeで正面・近接側面の両MP4が18.041667秒まで再生完了し、ミュート解除・映像のデコード・エラーなしを確認した。5〜7秒の着水前後、14秒の次の波、18秒の残る泡をフレームでも見比べた。大きな外殻と硬い小塊を減らし、浅瀬の細かな反射を戻したが、自然さを完全達成したとの判定はしていない。[映像・音声・ソースの検証記録](checks/v114/verification.json) · [最終テスト結果](checks/v114/tests.txt)

## 判定の限界

浅水場、波頭から出る水の運動、泡の群れと輸送場を組み合わせている。3Dの圧力場や空気の巻き込み、完全な体積保存を解く流体ソルバーではない。大きな巻き込みの厚さ、波面の広い滑らかさ、細かな飛沫にはまだ差があり、実写同等や砕波全体の完成とは扱わない。
