# V46 — 釣り・サーフィン・動作に連動する海の音

V45の実測海岸・浅水の入射条件を保持して、岸と停船中の釣り、新島のサーフィン、9素材を使う環境音を統合した。Fは道具の操作、Eは通常の調査・乗降と道具をしまう操作。既存のキー設定でFが使われている場合は、空いたキーへ活動操作を移す。

## 変更と実行結果

- 通常の泊の開始位置から竿へ歩き、浜から投げ、魚信に合わせて張力を調整し、メバル35cmを1匹取り込んだ。釣果の再装備による二重加算を防ぐ。魚は既存の海中モデルの体・鰭・眼を使う推定造形で、種固有の実測スキャンではない。
- 船のそばの検証開始点から、はしごで乗り、停船した船上でも35cmの魚を取り込んだ。操船入力で速度7.5735m/sに達し、竿を自動でしまうことを確認。最初は釣果が操縦台に隠れたため、船では魚を手元へ引き上げる配置へ修正して再度釣り、表示を確認した。岸の配置は保持した。
- 新島の現物のボードを拾い、浜から海まで運び、パドル・立ち上がり・転倒・帰浜を確認した。最終995c8edの海上チェックポイントからの記録は23.5887m / 10.0109秒の乗波、その後に浜へ戻って歩行・ボード保持へ移行。99標本、最後は接地し、眼高と床の差1.64m。島への全航海を通した一回の試験ではない。
- 停止中や衝突中に残る公称速度を、波の時間変化として誤検出しないよう、実際に受け入れた移動量から空間勾配の影響を除く。地図中は波の参照位置を更新し、立ち上がり入力を持ち越さない。転倒中でも浅瀬へ着けばボードを持つ状態へ戻る。2件の回帰テストを変更前に失敗、変更後に成功することを確認した。
- 通常開始位置から歩行・泳ぎ・潜水・船への接近と乗船、加減速を確認。別の船上チェックポイントでも最終の相対風を確認した。最大船速12m/s、最終の相対風最大11.576m/s。風向はFFTの実際の伝播方向と同じ定数から求め、島近傍の露出は滑らかな推定値を使う。
- 実際の潜水で最大深度2.615m、水中では風・岸の波の目標ゲインが0、カットオフ350Hz、呼吸・気泡へ変化。浮上すると空気100%と陸上側の音へ戻った。
- 内蔵ブラウザの静的HTTP版で、開発QAが存在しないこと、384万の元地形標本・247区画が保持されること、外部HTTP素材要求0、console error 0、9音すべての実AudioContextでの復号を確認した。音の観測用prototypeは復元済み。

## 音の証拠の範囲

生成素材9個・ループ7層、復号失敗0。ゲームの出力バスを直接録音し、マイクは使用していない。歩行、潜水、停船、操船、相対風とミュートの記録を保持。最終操船のデジタル出力は48kHz stereo、ピーク-11.635dBFS。NaN/Infなし。これらは音声経路とレベルの検証で、聴感上の自然さの承認ではない。

実UIのミュート・一時停止でAudioContextがsuspended、再開でrunningとなることを確認。dispose後は実contextがclosed、層0。visibilitychangeの制御試験もsuspended/runningを確認したが、内蔵ブラウザの別タブ選択はdocument.hiddenを変更しなかったため、ネイティブのタブ非表示による試験と区別する。ミュート録音の5秒は壁時計時間で、context停止によりメディアの実時間は約1.68秒だった。

音源は接続されたRunway経由で生成した合成音。最初の船べりの水音はElevenLabs backendのreceiptがあり、後続出力のbackend名は別途確認できていない。現地録音やCC0とは記していない。出典・処理・ハッシュは`src/assets/audio`に保存。

## 検証

コード995c8edで全410テスト成功（91.8587秒）、型検査、Vite、単体HTML生成成功。その後の釣果の配置だけの変更は型検査・buildと、実際の船上釣りの再実行で確認した。410は論理検証の件数で、写実品質の点数ではない。独立したGPT-6.1 Sol / lowのレビューで、E/Fの分離、キー移行、二重釣果、地図中の入力、音声経路、既存海岸の保持を確認。実行metadataと完了turnを照合した。実行権限はdanger-full-accessであり、read-onlyは担当への指示。

主要証拠は[checks/v46](checks/v46)。経路の通常入力、開発用開始地点、合成UI操作、制御したライフサイクル試験を混同しない。file://起動、全島の連続往復、実際のOSマウスによる全操作は今回の証拠に含まない。

## 残る見た目と全体目標

独立レビューで、水中の青い板状境界と近距離の尖った藻を検出した。rootのraycastでは尖った形は`brown coastal algae fronds`のinstance12。人体を隠しても変わらず、marine群を隠すと消える。青い境界は水面画素で、反射UVは有効。compositorの散乱影を無効化しても残る。反射depthのhit/no-hitと積分距離の不連続が候補だが、まだ確定していない。V46にはmarine・水面shader・compositorの変更がなく因果は検出していない。旧版を同一視点で撮った証拠は未取得なので「旧版でも実画面で再現済み」とはしない。

砂浜・岩・植生・海・水中・体・船の実写同等、海岸全域の精密な再現、全旅程、聴感評価は未達。崖の侵食と漂砂による動的地形更新も未実装。[海岸の形成と波](habushi-coastal-processes.md)に従い、実測時点の形状と長期的な堆積・侵食を分けて進める。最終紹介動画は全体の完成後に制作する。
