# V74 — つながる砕波と、水面に残る白水

V73の短い独立した波頭から、沿岸方向につながる砕波面へ進めました。波頭の落下、空気の巻き込み、着水時の飛沫、着水後に流される泡を同じイベントから生成します。実写と見分けがつかない品質はまだ達成していません。

![実際の連続描画から撮影した波](gallery/breaking-v74.gif)

[8秒のMP4](checks/v74/breaking-waves.mp4)。ゲームのChrome画面を連続録画したものです。生成映像、補間した中間フレーム、実写写真への置換は使っていません。GIFの末尾から先頭は再生上の切れ目です。

## 実装

- **波頭を連結する:** 現在の圧縮と浅水条件から、沿岸方向に17点の波頭を追跡。乾いた区間や逆向きの波面を避け、最大24本の短命な面として描画します。各点には共通のイベントIDと、不規則な崩れ始めの遅れがあります。
- **崩れる面の空気:** 先端が波の頂部から落ちた量で白濁を増やします。持ち上がる透明な面から、空気を含む白水へ移るための視覚近似です。
- **砂上の遡上と分ける:** 薄い水膜や平均水面より高い砂上の圧縮を、巻き上がる波頭として持ち上げません。そこは既存のSWEの遡上と泡で表現します。水膜の落下後は、付け根の高さでなく各頂点の実際の描画水面へ戻します。
- **着水で生む:** 先端が取得済みの実際の水面へ落ちた時に、各点につき一度だけ飛沫と泡を生成。飛沫の再着水も、小さい二次的な泡の発生源にします。残留している古い泡から新しい波頭は作りません。
- **世界座標の泡の履歴:** 192m四方・256×256のRGBA16Fを2枚使用。泡・水中気泡・小さな航跡の高さ・鉛直速度を保持し、岸際の符号付き流速で移流します。引き波は沖向きに運び、乾いた砂上の泡は残しません。カメラ移動には履歴を再投影し、島の地形データが変わった際は消去します。
- **時間をそろえる:** 履歴の更新は固定30Hz、表示フレームごとに最大3ステップ。泡と気泡は異なる寿命で減衰します。20/30/60/120fpsで更新した際のCPU側の経過時間と、一度だけの注入をテストしています。
- **船の発生源:** 動く船体の圧力と船尾の推進器を、実際の船の速度・向き・推力から同じ履歴へ入れます。停止した船から航跡を作らず、固定のV字模様は貼りません。小さな波の高さは描画と泳ぎ・船の高さ取得へ共通に渡します。
- **予算:** 履歴の2枚は合計1MiB。砕波面は1描画、最大18,432三角形。通常設定では旧方式の泡のカードを確保・描画しません。波頭と飛沫は1回の非同期読戻しを共有します。64×64・2m間隔・5Hz、符号付き流速を含め32,768bytes/回です。V73の4,608bytes/回より読戻し量は増えています。

通常設定で有効です。比較用の `marinefield=0&connectedbreakers=0` でV73の方式、`whitewater=0` で砕波面と泡の履歴を無効にできます。通常のゲームには切り替え用UIを追加していません。

## 確認と限界

正面・斜め・水面下・泊の穏やかな入り江・船上を確認しました。画像や動画の位置は開発用の観察開始点で、実測の撮影位置・当日の波浪条件ではありません。確認結果の数値と範囲は [検証記録](checks/v74/verification.json) に保存しています。

- 全体589テストに合格。最後の薄い遡上の発生域調整後に、影響する32件を再実行して成功しました。型検査・Vite本番ビルド・単一HTML生成も成功しています。
- Chromeの最高画質、1143×745で180フレームを観察。平均17.46ms、約57.3fps、95パーセンタイル18.1ms。録画を含むこの視点の値で、全島・全端末の性能やV73からの速度改善を保証する値ではありません。前面表示が安定する前には毎秒1回の制限も観察しています。
- 泊へ観察位置を移した後、泡・気泡・航跡高さが0へ戻ることをGPU上で確認。強い新島の砕波を穏やかな入り江へ持ち込みません。
- 既存の船の側面から通常の乗船操作を行い、操船状態・視野角78度を確認。通常の操船入力で速度12m/sへ加速し、船の移動とGPUの泡・気泡・短波の発生を確認しました。後方の見回しはマウス入力で行っています。開始地点だけが開発用設定で、浜からの全行程の証明ではありません。
- 地図を開いた1.2秒の観察では船のXYZ位置が不変、速度0。船上画像・状態は [wake](checks/v74/wake.png)、[乗船と操船](checks/v74/boat-proof.json)、[地図での停止](checks/v74/map-pause.json) に保存しています。
- MP4は7.93秒・1142×744・239フレームを再デコード。GIFは79フレーム・7.9秒。動画の符号化では時間を保持し、検証でも重複フレームを付け加えません。[映像の検証](checks/v74/media-verification.json)

今回の見た目の確認は主担当によるものです。独立した第三者の見た目レビューや、実写相当という人間の受入は得ていません。

波頭は2m・最大0.5秒の取得済み高さ場から作る視覚近似です。波頭の体積保存、波と岩の完全な3次元衝突、乱流や砂粒の輸送、流れ全域に対する船体の双方向連成は未実装です。航跡の短波は上限12cmの減衰する線形波で、実際の航跡の全波形を保証しません。

崖・植生の改善や、COLMAP/ODMによる現地写真群からの新しい形状復元は今回に含めていません。重なりと撮影情報のそろった現地写真群を新たに取得した根拠もありません。既存の測量地形と素材を保持し、海岸の弱い箇所は [改善リスト](improvements.md) に残します。
