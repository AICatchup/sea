# V54 — 3D点群の崖を接続し、通常採用は見送る

全体ゴールはACTIVE/UNMET。実写同等、全海岸の再現、通常操作による全旅程の完了とは宣言しない。[方法と残る差](research/sea-point-cliff-v54.md)。

確認済み:

- 元LASのSHA256、元10,853,673点からの抽出・Poisson再構成、出力の数値再比較。
- 固定組立CLIからrender SHA256とnative footprint SHA256を再生成。
- 関連93テスト、点群接続と境界の9テスト、native推定地層接続の1テスト、配布版へ候補を入れない変更後の関連27テスト、型検査・ビルド。27件は93件の一部を再確認したもので、独立件数へ加算しない。
- 実assetで40の独立ray比較。床と描画の最大差8.66e-7m、水深texelの確認、実Meshに対する3箇所の身体sweep衝突。これはCPU検証で、通常の歩行・潜水・操船の実プレイではない。
- 6視点の実WebGL静止画と独立の見た目の評価。接続前の大きな穴は減ったが、人工的な接続壁・欠け・丸い形状が残り、通常採用は却下。
- 配布版295,306,498bytes。候補を含めた338,305,790bytesの試作ビルドから、候補assetを配布版の埋め込み対象から除外した。開発用のsource・asset・再実行手順は保存する。

内蔵ブラウザでは静止画を実際の描画処理から取得した。一方、通常のrequestAnimationFrameは進まず、画面取得や接続にも失敗が残る。明示的な静止描画でこの制約を隠してFPSや連続入力が合格したとは扱わない。今回の通常入力・全旅程・音の再受入は未検証。

参照JPEGは原URL・撮影者の確認が未完了で、公式実写としての原出典証拠にしない。点群も高さ格子も現地1cm精度は証明していない。閉じた体積と任意overhang下の歩行も未達。動画は完成した実ゲームの体験を確認した後に作る。
