## 状態に連動する音

- [x] ElevenLabsを利用できる接続経路を確認し、船べりの水・柔らかな風・小型船外機・遠い鳥・船の軋みの音素材を生成し保存。ゲーム内ミックスと実音確認は以下の未完了項目。
- [ ] 風：環境風と移動速度から相対風を求め、速さ・向き・遮蔽に応じた自然な音量と音色にする。
- [ ] 波と岸：岸までの距離、波の強さ、浅瀬・外海の違いに連動する水音を作る。
- [ ] 船：実際の速度や揺れに応じた船底の水音、航跡、接合部・座席の小さな軋みを加える。
- [ ] エンジン：始動・アイドリング・加速・減速・停止を操船状態と同期させる。
- [ ] 人：砂や岩の足音、浅瀬の足音、泳ぎ、潜水時の呼吸・気泡、乗降や衣服の音を状態と同期させる。
- [ ] 生き物と環境：岸や島に近い場所で時折聞こえる鳥など、間隔・距離・方向に変化を付ける。
- [ ] 水中：空気中の高音を弱め、呼吸・気泡・水の音へ連続して変化させる。
- [ ] 音量を抑制し、静かな入り江で騒がしくならないようにする。ミュート・一時停止・タブ非表示・設定変更を確認する。
- [ ] 実際の出力を録音・再生し、繰り返しの継ぎ目、不自然な同時発音、音割れ、動作との遅れを確認する。

物理に沿った連動は実際のゲーム状態を入力とし、モデル化した近似を実測の完全再現と表現しない。
