# 海の調査を遊ぶ

右上の「操作」または **O** で操作設定を開けます。感度は **0.2〜3倍**、左右・上下の反転、各操作に2つまでのキー割り当てを変更できます。右へマウスを動かすと右を向くのが標準です。設定はこのブラウザに保存されます。以下は標準のキーです。

**M** で地図を開閉します。地図・調査ノート・操作設定を開いている間は、移動・航海・空気消費・チャレンジの時間が止まります。**Esc** で閉じてから、移動キーを押し直して再開できます。Ctrl・Alt・⌘はブラウザ操作用で、ゲームには割り当てません。

浜に流れ着いた調査ノートから、小さな海の探検が始まります。画面左の矢印・距離・水深を頼りに歩き、気になるものを見下ろして **E** で調べてください。**J** で調査ノートを開けます。

1. 波打ち際のシーグラスと、浅瀬の方位計を回収します。
2. 泊の調査ボックスまで歩いて戻り、Eで届けます。届けた記録がポイントになります。
3. ボックスのそばでもう一度Eを押し、装備を選びます。大容量タンクは潜水時間が45%増え、軽量フィンは泳ぐ速さが18%増えます。バッグは3個から5個へ広がります。
4. 海底のカメラ、ロガー、岩場のカプセルへ。見ている方向へ泳ぎ、**C**で潜降、**Space**で浮上できます。空気は水面で回復します。バッグが一杯なら拠点へ戻りましょう。
5. 水面の船の舷側まで泳ぎ、Eではしごを上ります。**W/S**で加減速、**A/D**で舵を取ります。停船してEを押すと下船します。
6. 地図から他の浜へ航海し、実際に上陸すると訪問スタンプが増えます。次の島にも回収できる記録があります。

ノートの「発見」で個別の手がかり、「冒険」で船や拠点、各浜を目印にできます。目印を選んでもプレイヤーの位置は変わりません。記録と装備はこのブラウザに自動保存され、次回は泊の浜から再開します。保存が使えない環境でも、そのセッション中は遊べます。

途中で別の浜へ寄り道しても、近くの未回収の記録を案内します。島の記録を拾ったら、船へ戻って泊の拠点へ届けましょう。自分で指定した目印は優先されます。

## 入り江の操船チャレンジ

J →「操船」からスタートを目印にして、船で近づきます。「チャレンジ開始」を押し、黄色く示されたブイの間を順番に通って戻ります。急な曲がり角では先に減速すると進みやすくなります。5区間の自己ベストを保存し、初回完走で2ポイントが増えます。泳いでの通過、自動航海、下船は記録になりません。

## 釣りとサーフィン

泊の浜にある竿へ近づくか、船を止めて **F** で竿を持ちます。水面を向いてFで投げ、浮きが沈んだらFで合わせます。取り込み中はFで巻く・緩めるを切り替え、張りすぎる前に緩めてください。**E**で竿をしまいます。歩き出す・操船を再開する・船から降りると釣りを中断します。

新島の羽伏浦メインゲート付近のボードへ近づいてFで持ち、歩いて海へ運びます。足が届かなくなったらFでボードを出し、**W**でパドル、**A/D**でターン。岸へ向かってパドルし、「立ち上がる！」が出たらF。大きく曲がりすぎるとバランスを崩すので、小さく修正します。転倒したらFでボードへ戻るか、岸まで泳いでください。浅瀬ではボードを持つ状態に戻り、Eで置けます。

活動のキーもOの設定から変更できます。釣った数・最長の魚・波乗りの最高距離はこのブラウザに保存します。地図や設定を開いている間は道具の操作も止まります。

## 景色だけを楽しむ

**H**で操作画面を隠せます。**Escape**で戻ります。波音とカメラは画面上部、天候と風は「海の表情」から。調査を進めずに歩いたり泳いだりしても構いません。

調査ボックス、機材、ブイコースと物語は、このゲームのために置いた架空のものです。実在する海岸の設備や漂着物の位置を表していません。
