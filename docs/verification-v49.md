# V49 — 波が引いた浜に残る湿り

乾いた浅水計算セルでも、床より15mm低い仮想的な水面が「濡れ97.5%」になる条件を修正した。水が実際に砂面へ届いた場合に限り接触を与え、薄い水膜と湿った色の履歴を分けた。波の強さ、測量地形、衝突、航路は変更していない。

## 海岸をどう理解したか

[東京都の羽伏浦紹介](https://www.gotokyo.org/jp/spot/244/index.html)は、約6.5kmの白砂と荒波の多さを記載する。[2020年の現地調査論文](https://doi.org/10.2208/kaigan.76.2_I_463)は台風時の侵食と、その後の浜・バームの状態を扱う。荒波の多い外洋海岸でも、波高・浜幅・波向が常に同じという意味ではない。瞬間の砕波・遡上・引き波と、荒天や季節を経る砂の移動・崖の後退を分ける。

[新島観光協会の堀切・シークレット紹介](https://niijima-info.jp/column/4724/)から以前保存した地上目線・海側斜めの実景を再確認。崖下の崩落斜面、淡い乾砂、波の届く濡れた帯、砕波帯のつながりを参照した。別の日・視点・光条件であり、画素一致や現在の浜幅の測量として扱わない。写真画素はゲームや公開資料へ同梱しない。

## 変更

- 現在の砂fragmentの高さと、描画と同じ浅水/沖波の水面を比較する。水面より上の16cmまで濡らしていた判定を除いた。2〜25mmの接触遷移は表示のための調整値。
- 地面に固定した192m四方・256×256のGPU履歴に、水膜と湿りを別々に保存。カメラ移動時は世界座標で再投影し、元の範囲外はゼロ。地形texture/version/bounds/resolution/補間契約が変わる場合やQA時刻変更時には初期化する。
- 水膜は0.8秒、湿りは130秒の時定数で指数減衰する。水膜は主に光沢、湿りは主に暗色へ反映。**現地で測った乾燥時間・土壌水分・浸透の再現ではない。** 固定の薄い湿潤帯も制作上の基底として残る。
- 高さの異なる隣接セルの履歴を減衰させる。独立レビューで、支持係数による除算がその減衰を取り消す不具合を指摘された。実際の受信shaderのGPU負例で再現してから、除算を除いて修正した。
- 追加は2MBのGPUターゲットと動作中の1パス。通常フレームでGPU readbackは行わない。履歴は局所的で保存されず、全海岸に永続する地形変化ではない。`sandmemory=0`で従来材質を比較できる。

## 検証

`61c16c3`で全422テスト成功（97.1432秒）。独立レビュー後の`e5ef083`では関連13テスト、型検査、Vite・単体HTML生成が成功。最終修正は受信側の支持係数と、そのGPU回帰条件。

実GPUの隔離fixtureでは、旧乾燥接触0.97528076に対し修正後0、本当の接水は1。排水0.8秒後は水膜0.36787945・湿り0.99386507、130秒後の湿り0.36787948。カメラwindow移動後も同じ世界地点の値が一致、新規領域・地形契約変更・範囲外は0。同一windowでpause中は追加パスなし。

受信shaderの斜面・単独隅セルは修正前に失敗。修正後は高さ差30cmの支持0.43200588、50cmの段差0、四隅のうち1個だけ湿潤なら0.25となり、平地の1を保持する。これは作った負例に対する計算の検証で、現地1cm精度の証明ではない。

同じカメラ・波・浅水状態・泡・照明で、新旧の材質だけを切り替えた広角と足元の比較を保存。20秒/12秒の広角、10秒の近距離連続描画で波の前進と接触帯を確認した。最初の観察は背景の更新抑制により12秒の待機中に0.45秒しか波が進まず、時間変化の証拠から除外。前面で実時間と描画時刻を読み直した。

独立したGPT-6.1 Sol / lowの診断と画像・コードレビューを実行。画像上の改善は局所的で控えめ。泡の平面感、規則的な水面、砂の均質さ、崖の反復する模様・形にはまだ差がある。斜面の指摘はrootがGPUの失敗→修正→成功まで確認した。

最終の単体HTTP版では開発QAが存在しない状態で、通常キーリスナーへの合成DOM入力により浜から約20m先の浅瀬へ歩き、元の浜へ戻った。272標本・1,504フレーム、1280×720/高品質で平均フレーム間隔18.08ms、最終X差0.035m、接地時の目の高さ1.64m。外部HTTP素材要求0、今回の読み込み以後のconsole error 0。全標本はwalkで、泳ぎ・潜水・全島航路やOSキー入力の証拠ではない。GPU専用タイマーや全域の性能保証でもない。

主要証拠は[checks/v49](checks/v49)。最終の広角・足元画像は`e5ef083`、レビューに用いた初稿の比較は`61c16c3`。紹介動画は全体の完成条件を満たしてから制作する。
