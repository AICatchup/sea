# V75 — 波頭の落下、白水、岸際の描画をつなぐ

砂浜に水が板状に残る症状、持ち上がったままの波頭、平坦な白い泡、視点移動に遅れる反射を修正しました。外部の海洋描画と流体研究を参照し、既存のFFT・浅水方程式（SWE）と泡の履歴へ組み込んだ改善です。完全な3次元流体ソルバーや実写相当の品質には到達していません。

![実際のゲームから収録した白水](checks/v75/poster.jpg)

[約24秒のMP4](checks/v75/breaking-waves.mp4)。新島シークレットを正面・斜めの2方向から連続収録しました。撮影用の固定視点、指定した風とうねりを使っています。現地の当日の波浪条件や実測カメラではありません。

## 今回の実装

- **巻いて落ちる波頭:** 波頭から岸側の低い水面を探し、落差と到達距離を求めます。十分な落差のある波には、上端が垂直を越えて巻く断面と重力加速度9.81m/s²の先端軌道を使います。小波は無理に大きな面を作らず、こぼれる泡と短命な白水で表します。
- **浮いた板を残さない:** 付け根の高さを毎フレームのGPU水面に合わせ、波頭の支持が失われたら面を消します。薄い遡上や平均水面より高い砂上は、持ち上げる波頭から除きます。各頂点と描画ピクセルの現在の地形・水深でも判定します。
- **落下と着水をつなぐ:** 先端の着水ごとに一度だけ飛沫、泡、短命な立体の白水を生成します。白水は約1〜2秒で崩れて平たくなり、符号付きのSWE流速に追従して引き波でも向きを変えます。泡の履歴はその後も水面へ残ります。
- **泡の素材:** CrestのMITライセンスの泡画像を改変せず採用しました。3方向への投影で巻く面を覆い、流速に沿う2位相の座標とミップマップで動かします。写真の輝度から光学的な微細起伏を導き、太陽と空の光で陰影を付けます。この起伏は計測した法線ではありません。
- **大きな波でも発生を抑えない:** 波頭が高くなった瞬間の水柱の厚さではなく、平均水面に対する水深で泡の発生域を決めます。波が高くなった途端に砕波の発生が弱まる問題を修正しました。
- **反射の更新:** 移動、回転、視野角変更、水面通過では反射画像と行列を即時更新します。静止時は既存の3フレーム周期を維持し、反射画像の境界も連続的にフェードさせます。

砕波面は24本の固定プール・最大73,728三角形、着水後の白水は256個・最大128,000三角形です。飛沫を含め3描画で、フレームごとの新規ジオメトリ生成はありません。泡の履歴は既存の1MiB、波頭と飛沫は同じ非同期の高さ・流速取得を使います。描画負荷が増えた部分もあるため、全端末で同じ速度を保証する値ではありません。

## 検証と残る差

影響する114テスト、型検査、本番ビルド、単一HTML生成を確認しました。Chromeで強い砕波の2方向、砂浜の水際、泊の浅瀬と海中を確認しています。開発用の観察開始点による描画確認で、浜からの移動経路を証明するものではありません。

MP4はH.264・1324×744・23.84秒、1,214フレームをすべて再デコードしました。元の可変フレーム時間を保ち、中央を16:9に切り出したものです。拡大、生成フレーム、動きの補間、黒帯の追加は行っていません。録画中のブラウザ描画は2視点で約59.9〜60.0fpsでしたが、MediaRecorderが保存した動画の平均は約50.9fpsです。ファイル転送もブラウザ側のSHA-256と照合しています。[映像・ソース・性能の検証記録](checks/v75/verification.json)

波頭は2m間隔の取得済み高さ場を用いる近似で、完全な体積保存、岩との3次元衝突、乱流、砂の輸送は未実装です。泡の細部、波頭の連結部、砕波時の水と空気の混合にはCGと分かる差が残ります。今回の見た目確認は主担当によるもので、独立した見た目のレビューと実写相当という人間の受入は得ていません。
