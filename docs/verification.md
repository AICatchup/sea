## 実行環境と結果

Windows、ChromeのD3D11描画、AMD Radeon RX 7600 XT。1440×900、描画品質「自動」で、夕凪・青い海・荒天・薄明をそれぞれ約3秒確認した際の表示値は59.6〜60fpsでした。長時間や他のGPUでの性能を保証する測定ではありません。通常のブラウザ実行でJavaScriptと描画のエラーは0件です。

証拠の到達点は **LOCAL_PASS** です。スマートフォン幅の確認は390×844のタッチ対応エミュレーションで行い、スマートフォン実機のDEVICE_PASSとは扱いません。デプロイ後のPUBLIC_PASS、実スピーカーでの聴感、ユーザーによる見た目の受入はこの記録に含めません。

## 波の計算

- CPUのスペクトルテスト6件に合格。決定的な生成、DC成分、共役対称性、Nyquist軸、方向分布、エネルギーと入力条件を確認。
- GPUで5つの解析波形を3時刻、x/y/zの3成分すべてと比較。最大誤差は0.000258329m。
- 2つの波スケールを1ステップ進める描画回数は34、中間FFTターゲットは4枚。
- 風変更直後と補間途中の再変更で、瞬間的な高さ差はそれぞれ0.000488282m、0.000976563m以下。
- 風2 / 7.5 / 18m/sの短波RMSは0.000976 / 0.060220 / 0.134749m。静かな海から強い風へ短波と白波が増えることを確認。
- 一時停止中に強風から弱風へ変更すると、古い白波が残り続けず再生成されることを確認。

波の解析解を使った検証は、シェーダーの計算手順を単に複製するテストとは分けています。方向分布・白波・散乱色は視覚モデルであり、観測海況との校正は行っていません。
