# V26–V27 — 羽伏浦の路面と海の反射（2026-10-07）

## 羽伏浦の灰色の面

実際の画面からraycastし、前景は道路の上面と確認した。路面は13.174579m、通常の歩行更新後の目線は14.814579m。これらはゲーム内座標で、現地測量ではない。カメラの埋没や垂直壁が原因ではなかった。

[新島村観光案内所のメインゲート](https://niijima-info.jp/spot/2216/)と、既存の正面・斜めの実景写真を見直した。前庭の位置と高さを維持し、無地に見える路面へ骨材・微細な凹凸・粗さの変化を加えた。元写真の画素はゲームへ転用していない。

素材は[Poly Haven Clean Asphalt](https://polyhaven.com/a/clean_asphalt)、Dimitrios Savva作、CC0。原本のDiffuse/OpenGL normal/ARM、実幅2.1m、MD5/SHA-256を記録した。現地の路面を撮影した素材ではない。新しいアスファルトの暗さを淡い路面へ調整する2.4倍の校正と、反射率の上限0.65は作者判断。落葉の多いWorn Asphaltは参照に合わず不採用とした。

細い道路継ぎ目を板で重ねると、斜めに見た時に黒い点線になった。18mm幅の線を画素が覆う割合で計算する方式へ変更し、サブピクセルの板を除いた。道路・縁石・塗装の位置、歩行支持、段差は保持する。通常有効で、`?pavement=0` は従来の比較用。

独立担当がA/Bの6枚と実景2枚を確認し、路面の限定改善として採用可能と判定。指摘された点線はその後修正した。rootは修正後の正面と、道路から中央通路を抜ける20秒の操作を確認。4つの記録点はいずれもwalk/groundedで、x=5837から5874.197へ移動した。検証用の開始地点を設定した後の連続歩行であり、島間航海の証拠ではない。

## 海色の大きな変動

同じ高所カメラ・昼・高品質・時刻34.016666666666666でも、水だけが暗いtealになる現象を調べた。固定seedの波なので、以前の「波の履歴差」という説明だけでは足りなかった。平面反射のon/off/onで水面法線・Fresnel・光路長・海底の遮蔽が一致し、反射textureのLOD0と縮小段階がともに黒になっていた。

実GPUで、反射の直後に画質をmedium→highへ変える操作から `FRAMEBUFFER_INCOMPLETE_DIMENSIONS (36057)` と `INVALID_FRAMEBUFFER_OPERATION (1286)` を再現した。反射先の読み出しも失敗していた。

ThreeのRenderTarget.setSizeは色画像を更新するが、DepthTexture.imageの寸法はそのFBOを次に描くまで古い。反射は3フレーム周期なので、間のwaterサンプラーが古い寸法で深度textureを先に初期化できる。その結果、色と深度のGPU寸法が合わなくなった。

色・深度の寸法を一緒に公開し、深度の更新を通知する小さなresize関数へ変更した。変更時には反射を無効にし、次のフレームで反射を即座に再描画する。samplerが保持するDepthTextureの参照は置換しない。既に深度だけが古い経路もFBOを無効化して回復する。独立したコードレビューで呼出順・dispose・参照保持を確認し、QA setterが更新待ちの反射を有効化できた点も直した。

修正後、同じresize操作、新規読み込み、水中、別の画面サイズで、FBOは `FRAMEBUFFER_COMPLETE (36053)`、GLエラー0となり、HDRの空の値を読み出せた。1280×720では色・深度とも538×302。別画面は実測961×540、反射先は両方404×227だった。通常の平面反射を無効にしたり、空だけへ置き換えたりした修正ではない。

## 検証と範囲

- 307テスト、TypeScript、本番ビルド、素材埋込HTMLの生成が成功。
- resize回帰は修正前に `537 != 538` で失敗し、修正後3件が成功。色・深度の同期、参照保持、不要な破棄の回避、古い深度の回復を確認。
- 路面のテストは支持面・塗装の位置、materialの色空間・実寸、所有textureの一回解放、dispose後の遅延読込を確認。
- 反射の実行証拠は[実行記録](checks/v27/runtime.json)。修正前JSONのcolorImage/depthImageは当時の参照オブジェクトが後の復元で変わる欠点があったため、寸法そのものの証拠には使わない。数値として保存したstatus/error、raw値、CPU回帰を使う。修正後は寸法もコピーして保存する。
- 水中では上面用の光学parameter probeを解釈せず、FBO状態・色/深度寸法・HDR値と画像を確認した。
- 大きいbundleのビルド警告は継続。GPUドライバーがsky関数に潜在的未初期化のコンパイル警告を出すケースがあった。今回の反射故障とは分け、エラー0という主張は確認したFBO操作のGLエラーを指す。

V25以前の水面が異なる比較を、地形・植生の改善による水色の変化として解釈しない。今回確定した反射故障を新しい根拠とする。
