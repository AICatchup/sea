# V48 — 枝分かれする海藻と、岩肌の見える付着層

大きい透明な帯に見えていた海藻を、閉じた茎・側枝・切れ込み葉・細長い気胞・冠葉・小さな付着器に置き換えた。12通りのseedによる形状変化を作り、主なモデルを正面・側面・上方から比較した。12種の海藻を同定・測量したという意味ではない。`marineplants=0`で従来版を比較できる。

## 実景から読み取ったこと

[式根島観光協会の海中写真](https://shikinejima.tokyo/play/diving/)の3画像を実見し、岩上の細かな枝状構造、隙間、薄い付着層と疎密を参照した。島内の紹介写真であり、泊の各地点・各個体の位置を証明しない。写真だけで生物種や実寸を特定していない。

[環境省の式根島港周辺の記載](https://www.env.go.jp/nature/important_wetland/wetland/w203.html)にはアントクメ、ヒジキ、ヤツマタモク、アカモク等がある。区域の代表的な記録で、現在の泊全域の植生図ではない。[神戸大学のアカモクの写真と説明](https://www.research.kobe-u.ac.jp/rcis-kurcis/kyoten2020/Awaji_seaweeds/seaweeds/brown/Sargassum_horneri.htm)で切れ込み葉と気胞・冠葉の形を確認し、滑らかな陸上の葉に見えた初稿を作り直した。大学の写真の産地・標本を式根島の現地測量に読み替えていない。

参考写真の画素はゲームに使用せず、公開成果物にも同梱しない。海藻の形、寸法、分布と動きは推定・制作したもの。

## 実装と近接比較

- 葉は画像板ではなく厚みのある閉曲面。側面・裏面・切れ込みを実形状にし、葉の中央へUVを対応させた。色用と微細な凹凸用のデータを分け、色だけsRGBにする。
- 葉自身が深度を書き、水面との前後関係と水中の減衰に使われる。茎の根元を保って曲げ、通常の描画と影に同じ変形を適用し、法線も補正する。揺れは同じ世界方向を基準とする制作上の近似で、実測の流速や流体・植物の連成計算ではない。
- 散布位置をずらした後の最終XZで床を取り直す。これまでの高さの流用による浮き・埋まりを防ぐ。付着器の地形支持であり、岩の表面への着生を復元したものではない。
- 既存の岩に沿う被膜は薄い半透明の層にし、下のスキャンの凹凸・模様を残す。葉の深度と、岩面から2.5mmの被膜の深度を同じ扱いにしない。

同じカメラ・1280×720・昼・波時刻34秒で、beforeとdenseの3組を保存。独立したSolの画像レビューでも巨大な帯状の破綻の解消と岩肌の改善を確認した。一方、疎な群生、側面の黒い小葉、角張った葉縁、根元が岩間に隠れる点は残る。

## 検証で見つかった地形の二重登録

詳細な屈折用の静的形状表を準備すると、海藻選択0件のまま処理上限を超えた。原因は実測地形247区画・7,672,002三角形が、別に存在する高さ場の経路と重複して登録されたことだった。

実測地形に`heightfieldSurface`を付け、既存の高さ場の経路に分けた。海藻も明示的な役割で静的形状表から除く。測量値・頂点・index・材質・補間・衝突は変更していない。回帰テストは修正前に上限超過で失敗、修正後に成功し、タグを外す負例も再び上限超過となる。

実行時は553,220三角形・1,794インスタンスで初期化成功。海藻・実測地形とも静的表の選択0件、描画用の384万標本と247区画は保持。衝突は3,241個・保存三角形489,224・29 BVHを保持する。詳細な屈折モード自体の既定値は変更していない。その高さ場経路は合成の砂材質を使い、すべての地形材質や変形する植物を光学的に完全再現するものではない。

さらに選択された岩・小物・小石の4本の光線を実GPUへ送り、独立したCPU交差と位置・法線・材質IDを照合。全4本がhitし、材質IDが一致した。少数の計算一致の確認であり、全場面や実物の精度の証明ではない。
