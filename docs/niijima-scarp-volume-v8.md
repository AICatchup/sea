# Connected scarp volume candidate v8

`new NiijimaScarpVolume(coast, coast.dem, pumiceMaterial)` builds one indexed closed mesh with 301 alongshore sections over an authored 420m frontage (Z-1000..-580), 47,558 triangles. It uses source shore stations and gradient directions with bracketed station search. Use source DEM `scarp:false`; query `volume=1` enables a separate shared rendered/support apron underneath the volume. The source raster is retained. Add the identical group to WorldSolidBinding extras; material/geometry ownership stays with the candidate.

The observed White Mama photo supplies the visual features: pale pumice, asymmetric vertical channels, thick horizontal beds, shelving and talus. Dimensions and hidden sections remain hypotheses. No Google pixels are embedded. The top/back is anchored to source DEM; the current maximum Y111.23m includes the roof, not a surveyed new cliff height. The shoreline corridor at source shore distance12m stays invariant.

Root captured frontal, reverse and close viewpoints. Independent image review REJECTED default promotion: end transitions expose large white pointed slopes, close shelves are too rounded and vertical fissures/porous grains are insufficient. Closed manifold indices do not prove no self-intersections or burial of all end caps. Both geometry and apron stay query-only. This is a bounded experiment, not a full coast reconstruction or photographic result. See [current acceptance](verification-v8.md).
