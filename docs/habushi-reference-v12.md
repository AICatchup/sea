# 羽伏浦全岸の実景・波・地質 — 2026-10-02

実写と見分けがつかないという受入条件は未達。今回は公式地図の実画素、原動画、地質・現地測量原著を照合し、描画の具体的な欠陥へ接続した。資料を増やしたことやCPU検証を、写真品質の達成として扱わない。

## 全岸の配置

[2026年公式A3地図](https://niijima-info.jp/cms24/wp-content/uploads/2026/06/niijimaA3MAP.pdf) の第1頁を実PDFから2800px PNGへレンダリングし、図上の名称と配置を視認した。島は紙面上で回転しているため、紙面の上下を南北と読み替えない。羽伏浦展望台・漁港が北側、メインゲートと正面、ヘリ下、堀切入口と堀切、シークレット、白ママ断崖が沿岸に続く。堀切の写真には狭い切れ込み、両側の地層、階段と砂浜の接続がある。漁港には「現在使われておりません」の注記がある。これは2026年5月の案内情報で、航海可能な港の実確認ではない。

縮尺と北矢印は視認したが、観光図の記号中心を測量座標へ変換していない。2018 GSI由来の約6727m候補は歴史的な水平骨格で、約6.5〜7kmという観光概数や2026現在の測量長と同一視しない。元PDF・参照画素は作業用 `work/habushi-evidence-v12` のみで、ゲーム素材へ同梱しない。

## 地形と粒感を一種類にしない理由

[梅田ほか2020年・現地研究](https://www.jstage.jst.go.jp/article/kaigan/76/2/76_I_463/_pdf/-char/ja) §3・5、図5では2018年と2020年の同じ3測線をRTK-GPSで比較している。護岸南端から10m／220m南の測線で崖後退10.7m／4.7m、北側では侵食後に標高+4mのバームが形成された。2015年の護岸両側の前浜幅にも65m／28mの差があった。これらを全岸の一様な後退量、現在の浜幅として適用しない。崖線・乾砂・濡れ際・バームを別の観察対象にする。

[地質調査所の1995年原著](https://www.gsj.jp/data/bull-gsj/46-09_02.pdf) は新島南東部の大海食崖と火砕丘の層理・崩壊を記録する。海側へ約35度傾く層理をすべての白ママ面へ一律適用しない。層の硬軟、縦溝、棚、崖錐を実景に合わせて分ける。

[新島村博物館H14紀要](https://niijima.com/facility/community/hakubutsukan/files/H14_kiyou016_ocr.pdf) pp28–29は採取試料の海浜・砂丘・白ママ下崖錐を比較し、砂丘の細粒化と石英増加、崖錐試料の軽石100%を報告する。軽石100%は採取した崖錐試料であり、白ママ全体や砂浜全域の組成ではない。マテリアルの場所ごとの違いを裏づける資料として使う。

## 波の原映像と条件

[Allen Moriの羽伏浦映像](https://www.youtube.com/watch?v=RKgTU7eZyWw) を実ブラウザで再生し、説明の撮影日March27th2022、7:59の長さ、プレイヤー速度1を確認した。約20.77秒では長い曲がった波列と岸際の白水帯、231.019〜231.354秒の取得画素では青緑の厚い波面、局所的な崩れ、立ち上がる飛沫、手前に残る起伏ある白水を視認した。動画の編集・元の撮影速度・撮影尺度・潮位・波高・周期は未校正。プレイヤー速度1だけで実時間の周期を計測したとはしない。

[撮影者の2011年旅行記](https://www.surfinginjapan.com/stories/nijima-trip-2011) は透明な海色とほぼ無風でも台風うねりが大きかった例を記録する。風による細波・うねり・透明度を独立して評価する理由になる。作者の6–10ft face推定を計器測定とせず、サーファーまでの300mを波長としない。[船木氏の体験記](https://www.nakisurf.com/blog/naki/archives/5270) は非常に浅い小波のショアブレイクも記録するが、その一日を平常条件の代表としない。

2020年論文のH1/3=13.2m、周期14.1秒は羽伏浦の北西48kmの石廊崎での2019年台風観測である。羽伏浦の通常日や今回の2022年映像の再現値へ転用しない。

## 今回の描画比較と次の受入

同カメラ・同FFT時刻の沿岸solver ON/OFFを1280×720で保存した。シークレット位置5898,-923.918、時刻46.066、風8.5・swell1は作業用比較条件で、現地の実測条件ではない。ONの中央右に鋭い暗い水面の張り出しがあり、OFFでは消える。地形の継ぎ目と断定せず、水面の変位座標と接触判定の不整合を検証する。

この条件でvolume白水のactiveは0、12秒でemit1、solverの最大foam約.439。原動画の厚い崩れと混相白水には達していない。平滑な白い斜面、白い均質なゲート、泡・飛沫の不足、海の濃い色も引き続き実写との差として残る。全岸を近接・中景・反対方向から確認し、地形・岩肌・砂・植生の多方向品質を通す必要がある。
