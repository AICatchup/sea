# V40 — 海側の偽の壁を除去し、白ママの立体的な侵食を追加

ユーザー画像にあった、シークレットの海側に続く尖った壁・階段状の尾根を修正した。元のGSI DEM5欠測部をDEM10Bの2×2複製値で埋めた場所に、細かな海岸端と矛盾する高い列が残っていた。実際のDEM5A/5B・航空写真・複数方向の海岸写真を照合し、低い有効DEM5端から東へ連続する粗い補完だけを抑制した。

## 地形と実景の対応

- 対象は1,968セル・196行。細かな有効値、内陸欠測、高い崖端は保持。原本の生成ファイルは変更せず、寸法・位置・全データのハッシュ・各旧値が一致したときだけ別コピーへ適用する。
- 新しい海底は依然として推定。欠測が海を意味すると一般化した処理ではない。再現は `python scripts/build-niijima-coast-confidence.py --verify --cache-dir <保存したGSIタイル>`。Python/NumPy/Pillowを使用する。
- 地形に沿う閉じた崖メッシュへ、大小の雨溝・途切れる薄層・欠けを追加。斜面では弱め、崖脚と境界は彫り込みを滑らかに消す。実体8メッシュ・375,808三角形。56,832枚の元三角形だけを置換し、同じ判定を歩行の床へ使う。
- 2.7m実寸のCC0 Rock Face 03を表面の細部へ登録。茶色を中性化した類似材質であり、新島の現地スキャンではない。画像を向きの固定された板として並べたものではない。粗さ・法線・薄層の陰影を実3D面で評価する。

[新島観光協会の堀切・シークレット紹介](https://niijima-info.jp/column/4724/)、[massan4632撮影の白ママ断崖](https://commons.wikimedia.org/wiki/File:Tokyo_to_Niijima_mura_Shiromama_danso_20190527.jpg)、[Ka23 13撮影の海上からの白ママ断崖](https://commons.wikimedia.org/wiki/File:Niijima_20221203_122020.jpg)を実際に閲覧。Googleマップ航空写真とGSI全国最新写真も形の参照に使用した。写真の画素はゲーム素材へ転載していない。写真の撮影方向・光・潮位はゲームと同一ではなく、ピクセル一致の根拠にはしていない。

## 検証

361テスト、型検査、Vite、単体HTMLビルドが通過。独立した有限検査では、削除する全56,832三角形の重心と辺付近、計227,328点で床の欠落なし。189点の実描画メッシュへのレイと床は最大8.53e-14m差。海岸の水深テクスチャも現在の床を使用することを確認した。

内蔵ブラウザでは、シークレットの浜を開発用の開始地点として、歩行→泳ぎ→潜水→浮上→歩いて岸へ復帰を連続実行。500サンプルを保存し、最後に接地を確認した。開始地点への移動そのもの、OSの物理キー長押し、全島の航路はこの検査の対象外。

配布HTMLを静的HTTPで実行し、開発QAが存在しないこと、外部素材通信0件、console error0件、修正が通常設定で有効なことを確認した。`file://`起動は未検証。

6方向と別方向の日光で見え方を確認した。独立レビューは限定改善として採用可。**水際の多角形、崖脚の小さな段・尖り、大きな層の均一さは残る。全体の実写品質、現地との1cm一致は未達。** 実測点群による次の改善と、保全している活動・音の候補は別途継続する。
