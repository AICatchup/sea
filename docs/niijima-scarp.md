# Secret / Shiromama opt-in physical profile candidate

This candidate replaces the authored smooth near-Secret slope with a connected height-field scarp, a low strand and grounded talus. It reparameterizes the immutable source DEM along the local inland shore-distance normal, rather than adding disconnected cliff objects. `new NiijimaDEM(undefined, { scarp: true })` enables it. The default is legacy. Root must enable the southern DEM only, then review GPU views before promotion.

The bounded authored domain is X 5720..5970, Z -1500..-450 world metres. Its X joins feather over 30m/25m; Z joins over 100m/160m. Existing source heights <=3m, shore distances <=12m and >=145m, all outside points, and measured `heightAt` values stay unchanged. The field adds zero triangles, meshes, textures or collision bodies. Existing `NiijimaSurface` creates the render grid and its barycentric ground query from the same candidate field. Existing 2m local grid is sufficient for the approximately 12m face transition; root must confirm the actual grid in GPU capture.

The reviewed screenshot-only Google reference is the May 2024 sapphirepeace White Mama photograph. It shows steep layered cliff faces, rain gullies and sloping toe debris. The photo's exact camera position, metric dimensions and absolute scale are unknown. The screenshot is not copied into deliverables. The existing Secret baseline screenshot has an overly smooth inclined white slope. Its metadata is X5898, Y2.107078066180053, Z-923.918, yaw PI, pitch -.04, high quality, day, 1280x720; it is visual-only and has no human acceptance or movement verification.

CPU samples confirm crossshore direction: at Z-924 the original heights at X5800/5860/5900 are 61.8/21.4/.2m; shore distance decreases eastward approximately 1m/m. This candidate uses the actual local shore-distance gradient rather than assuming the direction globally. Along Z-924 the candidate heights at X5858/5870 are 44.84/3.54m versus legacy 22.60/14.55m. This is an authored steepening, not a measured survey reconstruction. Smooth unequal world-space frontage shifts define continuous gullies; finite bedding offsets form physical ledges in the face profile.

The 2m domain sweep measured maximum absolute displacement 55.738414m at X5844,Z-1192. This is sampled evidence, not a mathematical upper bound. A denser survey and oblique GPU inspection remain pending. Local original low strand values remain identical, including the Secret walking corridor selected from source shore distance and its seaward offsets through 90m. This proves sampler invariance there; it is not an end-to-end boat or foot route test.

Validation: TypeScript `tsc --noEmit` passes; `tests/niijima-scarp.test.ts` has 3 passing cases covering immutable raster hash/decoded source arrays, finite samples, default-off behavior, low strand and outer negative paths, continuous domain joins, substantial scarp steepening, bounded sampled displacement, corridor invariance, and shared indexed surface interpolation.
