# V79 — 岸向きで判明した破綻の除去

V78は岸向きで浮いた青い破片と不自然な接続を生じるため、写実的な砕波として受け入れない。ユーザーの添付画像を基準に同じ岸向きで再確認した。

## 変更

- 下の海面とは独立した巻き込みメッシュと、その着水用ローラーを通常表示から除外。`breakinglips=1` の実験用に保持。高いうねり、浅水計算、飛沫、海面の泡は残す。
- 薄い残留泡の被覆を `1-exp(-4.2*c)` から濃度 `c` に変更。低濃度を何倍にも増幅して白い膜にする処理を除去。
- 気泡による白濁の低濃度側の応答と上限を低減。

## 確認

Chromeの岸向き視点で18秒間に計算時間も18.049秒進行。波頭の独立メッシュ数0、浮いた青い破片は観察されなかった。GIFは239フレーム、15.94秒、239個の異なるフレーム。関連117テスト合格、型検査・ビルド成功。

## 未達

これは破綻した表現を通常表示から除く修正。物理的に連続した巻き波を実装し終えたわけではない。砂浜の形の単調さ、水際の白い面、実景との大きな差は残る。今後の巻き波は元の海面との位置・速度・体積の整合を保ち、接続から着水までの側面映像で受入する必要がある。見栄えのよい一瞬やテスト合格だけで完成としない。
