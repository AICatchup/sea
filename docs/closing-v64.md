## 開き方

保存した `SEA.html` は全素材を含む約358MBの単体HTML。静的HTTPで配信して開く。`file://` 直接起動は未検証。ソース版は Node.js 22.13以降 / 24系とpnpmで以下を実行する。

```sh
pnpm install --frozen-lockfile
pnpm dev
# 保存版を作る
pnpm build
```

`WASD`移動、ドラッグで見回し、`Space`ジャンプ/浮上、`C`潜降。`E`で現地の調査・船への乗降、`F`で釣りやボードの活動。`M`地図、`J`調査ノート、`O`感度・反転・キー設定。船上のホイールで視野角を調整できる。浜のノートから始め、回収品を泊の拠点へ届け、装備を強化する。[遊び方](gameplay.md)。

## 残件と再開点

1. 崖脚の面接続、岩/砂の材質、遠景と植生、人体・船の細部は実写同等ではない。測量データとの整合を現地1cm一致とは呼ばない。候補の `tomarisurvey` / Poisson地形を通常ONにしない。
2. 人体はモデル・UV・動作・道具との接触を一括して検証する必要がある。立ち姿だけの変更で解剖学的な形状や歩行を解決しない。
3. 自然音と各動作の同期・聴感、全島の往復・活動・帰還・納品・保存復帰は、現在版の一連のプレイとして未受入。
4. 要求全体の完成後に作る紹介動画は未作成。今回のクローズを、写真品質や最終動画の完成に読み替えない。

再開依頼があった場合は、この記録、保存manifestのcommit、現在のmain/dirtyを先に照合し、残件から一つを選ぶ。全体調査や素材取得を最初から繰り返さない。詳細な未完了項目は[チェックリスト](experience-checklist.md)に保持する。
