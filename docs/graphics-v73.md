# V73 — 波頭の落下から着水後の泡まで

## 変更

- 通常の海に最大96個の短命な波頭を追加。浅い水域の現在の圧縮から発生し、張り出した先端が重力によって落ちる。
- 先端が取得済みの水面へ達したときだけ、その着水位置で泡と短い飛沫を生成する。同じ波頭の着水イベントは一度だけ。
- 泡を水面の曲率に沿う固定格子へ変更。二枚の三角形が波をまたいで水面へ埋まる問題を軽減。
- 波頭の付け根を描画中の水面へ接続。端の頂点を画面外へ飛ばしてしまい、三角形が伸びる問題を修正。
- 通常設定で有効。比較用 `breakinglips=0`、全泡の停止 `whitewater=0` を維持。旧 `breaker=1` と実験的な `whitewater=volume` は別機構で、通常設定には追加していない。

## 検証

- Node の全テストを実行し終了コード0。追加6ケースは落下・一度だけの着水・停止・時間分割・欠損キャッシュ・プール上限・泡生成の因果関係・格子内部の水面サンプルを確認。
- TypeScript `--noEmit`、Vite本番ビルド、単一HTML生成が成功。
- Chrome の実GPU描画で正面と斜めを観察。最後の通常設定の正面収録では、着水264回と泡生成264回が一致。稼働中の波頭15、泡125、読戻し失敗なし。これは収録終端の累積値で、全粒子が画角内にある意味ではない。
- 読戻しは従来の576点・4608 bytes・0.2秒間隔を共有。波頭で1 draw追加。泡は最大49152三角形、波頭は最大55296三角形。速度改善を実測したという主張ではない。
- 正面のMP4は8.799067秒、1144×745。再デコードからGIF64フレーム・8秒を作成し、全フレームの読み込みを確認。斜めMP4は9.728767秒。
- ローカル成果物: `outputs/breaking-waves-v73/`、保存版 `outputs/releases/v73/sea.html`（プロジェクトのトップ階層）。

## 見た目と限界

水面の上下運動だけだった部分に、張り出し・落下・着水・残留する泡の連続動作を追加した。撮影条件は開発用視点と指定した風・うねりであり、実測の天候ではない。波頭は6m間隔のキャッシュから生じる短い水膜の近似で、体積保存する流体計算や沿岸全域の一枚の巻き波ではない。大きな連続した砕波面の形状、広い白波の密度、実写相当の写実性は未達。実験的な立体泡に硬い塊のような輪郭が残ることも確認し、通常設定への採用を見送った。
