# V10 — 羽伏浦の浅瀬候補と全岸参照

実写同等の受入は **UNMET**。既定へのsurf候補採用は見送り。通常のFPS世界を保ち、開発用 `?surf=1` に深さ積分の有限体積計算を追加した。巻き波の空洞や落ちる水膜を表すモデルではない。

## 実装と検証範囲

128² / 192m / RGBA16Fの水深・水平運動量・泡をGPUで時間発展させる。現行FFTが境界水位を供給し、浅瀬の伝播と圧縮を計算する。Niijimaの水深マップだけで動作し、他の島・沖合は従来の水面。1.5mのセル、一次精度、作者による海底、地形勾配による入射方向の近似であり、測量された砕波ではない。

水面の立体、法線、既存512Bの浮力用cache、海中の光、飛沫用cache、白水の頂点が共通の高さを使う。通常frameで追加のGPU readbackはない。明示した比較QAだけが128²の状態を131072B読み取る。

独立コードレビューが乾燥ノードの地形を水面へ補間するP1を指摘。湿潤ノードだけでetaを補間し、etaと照会地形の差でwet blendを判断する修正を行った。同じreviewerが反例の解消とrootの接続・pause・disposeを確認。倍精度1D参照5件は静水、周期境界、wet/dry positivityと補間の確認で、GPU静水平衡や全海岸の物理精度を証明しない。

## 実GPU画像

同じFFT時刻・光・視点で候補ON/OFFを1280×720に保存した。OFFは既存particle履歴を維持した水面切替であり、独立した初期条件の旧モデル再実行ではない。シークレットで約10.88秒、羽伏浦正面で約11.67秒、水際で約11.68秒の計算を実行。正面と水際の16,384セルは非有限値0、水深最小0。正面の最大水深3.201m・最大速度11.83m/s、水際9.266m・7.509m/sはモデル出力で実測値ではない。droppedSecondsは0。正面のカメラはゲート側の高所、水際は作者の比較位置x5940,z-4503.84。

シークレットでは波高と青緑の波面が明瞭になった。一方、独立した画像reviewは均一な管状の波頭、直線的な遡上端、塗料状の泡を指摘し既定化を拒否。水際の別視点でも平らな反射帯と大きい泡が残る。テストや一枚の画像を実写同等の証拠にしない。
