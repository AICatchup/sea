# 東京都の実測地形 V41

[東京都デジタルツイン・島しょ地域点群データ](https://www.geospatial.jp/ckan/dataset/tokyopc-shima-2023) の **09QC1711** 区画を加工して作成。著作者は東京都デジタルサービス局、表示ライセンスは **CC BY4.0**。[ライセンス](https://creativecommons.org/licenses/by/4.0/)と[配布元利用規約](https://gic-tokyo.s3.ap-northeast-1.amazonaws.com/2023/dig/doc/license.pdf)を参照。計測期間はカタログ記載の2022年7月〜2023年1月で、現在の浜の形を保証するものではない。

地形は配布元が処理した0.25m GeoTIFFを採用。1600×1200のPixelIsArea標本中心を保持し、格子を一律0.5mへ間引く試作は急崖で最大約7.4mの高さ損失が出たため採用しなかった。元のTIFF・ZIP SHA256、座標変換、cm整数格納による量子化を生成ファイルへ記録した。

原点はJGD2011／平面直角座標系第IX系(EPSG6677)。投影GeoKeyとカタログはJGD2011を示すが、TIFFの地理系自由記述にはJGD2000という古い表記が残る。配布宣言と投影GeoKeyを採用した。SEAの緯度経度原点へ変換するpyprojの公称変換精度は1m。元格子の全192万頂点と比較した局所座標変換＋高さ格納の数値誤差は最大約6.1mmだが、**これは現地との1cm測量精度ではない**。

表面の192万標本を保持し、130区画に分割して表示。格子の同じ三角形を描画・歩行の床に使う。外周12mは既存地形、32mで実測値へ接続し、この接続帯は元標高そのものではない。高さ場なのでオーバーハングの復元や完全な崖スキャンとは呼ばない。類似する別地点のCC0岩材質は現地の撮影色とは区別する。LASの点色をそのままゲームalbedoへ転用していない。

`python scripts/build-niijima-native.py --archive <09QC1711-grid25.zip> --verify` で元配布データから再現できる。NumPy、tifffile、pyprojを使用。変換結果が変わると検証は失敗するため、新しい環境や投影定義へ無確認で更新しない。
