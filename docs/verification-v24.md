# V24 — 遊べる海の調査（2026-10-06）

実装は `38aa5ec652fd5301142937b1adfd3d21bb8a1b7c`。基準は公開main `5abd15d4859f00e6bf794d01ad8b4dadb7c5a429`。海岸の実写品質という元のゴールを維持し、今回は「楽しいゲームとしてプレイできる」部分を追加した。

## 追加した体験

浜のノートを読む → 浅瀬の発見物を回収 → 拠点へ持ち帰る → 装備を強化 → 深く潜る → 船で島を訪れる、という進行を同じ世界へ追加した。9個の回収品、3段階の装備、7つの既存到着地点の訪問スタンプ、5区間の操船チャレンジを持つ。手がかりはJのノートで選べる。目印は距離と方向を示し、位置を書き換えない。[遊び方](gameplay.md)を参照。

回収は距離・視線・水深・地面の遮蔽を確認する。荷物には上限があり、拠点へ届けると一度だけポイントになる。装備は表示だけでなく実際の泳速と空気の消費へ作用する。船と徒歩の既存のE操作を共有し、船への接近とはしごの動きを保持した。コースは地形と船幅から通れる水域に置き、順番通過・移動の連続性・手動操船を確認する。

進行はlocalStorageへ保存。未知のID、重複、異常なタイム、過大な装備購入を保存読込で検査する。保存が拒否されても遊びは続く。開発用 `?capture=1` はセッションのみ。保存の実行検証には `?capture=1&qaSave=1` の専用キーを使い、通常のユーザー進行へ検証データを入れない。

拠点と機材を実際の地面へ接地させ、回収後は描画から消す。ノートから地図へ移る時のフォーカス、行き先が無効な徒歩状態で地図の閉じるボタンへフォーカスする処理も修正した。

## 実行した範囲

- 通しプレイは通常の開始位置から始め、ノート、シーグラス、方位計を回収し、拠点まで戻って納品。UIで大容量タンクを装備した。その後、同じ旅を続けて海底のカメラ・ロガー・カプセルを回収、浮上、船の舷側へ泳ぎ、Eで乗船した。
- コース開始をUIで押し、舵と加減速を入力して5区間を完走した。今回の記録は63.8秒。検証プログラムによる操舵であり、人間のプレイヤーによるタイムやゲームの楽しさの受入ではない。
- 移動は既存のタッチコントローラーと同じ入力経路を使用。E、J、ドラッグ、ダイアログ内のボタンはブラウザの操作を使用し、一部の水中回収は同じコントローラーのinteractを呼んだ。姿勢・座標の直接変更や島間ワープを通しプレイの証拠にしていない。物理キーボードの長押し検証とは区別する。
- 通しプレイの後に、機材の接地、コース中の案内文、ノート→地図のフォーカスを仕上げた。これらの修正後にノートを再取得して保存・リロード復元、390×844のノート表示、地図への遷移、Escapeでの復帰、ブラウザエラー0件を確認した。通しプレイの画像を全て仕上げ後の画像とは扱わない。
- テスト結果、画像と記録のハッシュは [runtime.json](checks/v24/runtime.json)。298件が合格し、装備が実際の操作へ効く検証、回収・納品・保存・重複防止、コースの船幅、機材の接地を含む。TypeScript、Vite、素材埋込HTMLの生成を実施。大きいbundleの警告は残る。

## 未達と次の検証

この追加は架空の探索ゲームであり、現地にある機材・調査活動・海底測量の再現ではない。全島間の実操作走破、各島の回収品を全て持ち帰る旅、実機タッチ操作、長期のセーブ移行、プレイヤーによる楽しさの評価は未検証。今回追加した音の短い通知も実聴の受入は未実施。

実写と見分けがつかない品質、全海岸の正確な再現、独立した最終見た目レビュー、Human受入は引き続き未達。特に崖の大形状、植生の密度、海色、水中の景観、体・手・船を継続改善する。保存版HTMLの生成は、その大きなHTMLのブラウザ起動を証明しない。

最後の成果物として、完成した実際のゲームを録画する。浜から始まる一連の遊びに、広い海岸・岩肌の近景・透明な水際・海中の光と生物・乗船と航海・羽伏浦とシークレットの景観を織り込む。架空の生成映像を実機プレイとして使わず、完成後に紹介動画へ編集し、保存した動画自体を再生して確認する。この最終動画はまだ制作していない。
