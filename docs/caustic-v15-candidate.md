# V15 fine-density caustic candidate

Status: LOCAL_PASS for CPU reconstruction, resource switching and TypeScript only. Candidate remains opt-in; GPU shader compilation, raster energy, visual acceptance and default promotion are unverified.

API: `new WaveCaustics(renderer, { photonResolution: 512 })` or `caustics.setPhotonResolution(512)`. Return with `setPhotonResolution(256)`; inspect `photonResolution`. Existing defaults remain 256 photons per axis, 512 target pixels and unchanged span. No renderer/material intensity, scattering, albedo or spectrum changes.

Fine uses 512² = 262,144 incident photons versus legacy 256² = 65,536 (4× vertex work). With a 32m receiver span the 48m incident domain has .09375m cells instead of .1875m. The existing normalized Gaussian support remains at least 1.70 cells and .14m, plus unchanged solar/path/wind broadening. Consequently zero-depth support is .159375m versus .31875m at this span; this is a denser incident lattice, not an arbitrary sub-cell narrowing. Photon energy remains cell² divided by radius² and the disk kernel integral. The actual renderer short FFT is 128² over24m. Fine surface derivatives sample at half of its texel spacing (12/128=.09375m), derived from the supplied texture width during update. This samples the existing bilinear surface more locally and introduces no new FFT frequencies. Legacy photon modes128/256 retain their original .1875m difference spacing. This remains a surface approximation, not capillary CFD.

Geometry is allocated lazily once for each requested member of {128,256,512}, at most three variants. Default constructs only the original 256² geometry. Position storage is .75MiB legacy and 3MiB fine (3.75MiB retained after the usual A/B); all three variants total 3.9375MiB. Three existing 512² RGBA half-float targets remain 6MiB total; no new render targets, materials or per-frame geometry allocations. Actual GPU cost requires measurement, since overlap and fill cost do not necessarily increase 4×.

A density change couples normals and photons and invalidates only caustic history. The next update clears both history targets and uses zero history weight. Same-density calls are no-ops. Switching back reuses its geometry. FFT textures, shore uniform objects, bathymetry and solver time remain borrowed and untouched. Dispose releases owned resources exactly once and never disposes borrowed textures.

Frozen A/B: hold world/FFT/shore inputs, camera, sun and time fixed; switch density; run one caustic update with the same time (delta zero is suitable), then render/capture. Switching alone leaves the old output texture until this update, so do not capture between switching and updating. Capture legacy→fine→legacy to reveal drift. Camera bounds snap to each density's source cell; this is intentional world-lattice alignment and both passes must be captured after update.

Required root GPU counterexamples: flat water at each density must show no source grid and bounded mean irradiance; angled sun/deeper water must retain solar blur, proper gating and energy; dry/above-water and invalid paths must receive no photon injection. Verify fine versus legacy at the same frozen time through reef, sand and multiple depths/camera angles, including motion for temporal instability. Check 512 target pixel filtering does not erase the added focus or create aliasing; inspect device point-size limitations and clipping. Fine cannot be promoted from a bright single image or CPU tests.
