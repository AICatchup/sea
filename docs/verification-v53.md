# V53 — 崖と植生を優先、外部実装を実データで検証

海を現状の基準とし、崖・植生を優先するユーザー訂正を反映した。[外部実装と実点再構成](research/sea-external-methods-v53.md)を参照。

通常表示のゲームコード・素材はV52から変更していない。2つの見た目の候補を同条件で比較し、採用せずに保存した。

- 崖のランダムな素材混合＋細い地層線：近景・正面・海岸沿い・沖合の4視点でA/B/A。水平線が石積みのように見え、独立レビューも不採用。形状の不足は解消しなかった。
- 樹冠の画面上の大きさを使うLOD選択：3つの通常視点と2つの近い視点でA/B/A。通常の比較では変化が0〜0.43%の画素に留まり、独立レビューでは有意な改善を確認できなかった。通常採用を見送った。

候補検証時には崖・地形・植生の20件の関連テストと型検査が成功した。これは候補の写実性を保証するものではない。候補を退避した後、全ランタイムファイルのGit blobがV52のHEADと一致することを確認した。今回の公開変更は研究・再構成スクリプト・検証記録であり、ゲーム全テストやビルドの新たな合格を主張しない。

新しいスクリプトは実際の元LASアーカイブから実行し、60,985点のclass 2 ROI、13,456点の急面選択、16,158/19,260三角形の出力を確認した。ファイルの再実行結果を[保存](checks/v53/sidewall-receipt.json)した。元点の留保試験は[別記録](checks/v53/holdout-receipt.json)。内蔵ブラウザでは高さ場と元点の再構成を同じカメラで比較し、未再構成の穴が残ることを確認した。

全体ゴールはACTIVE/UNMET。テスト件数、取得したリポジトリ、生成した面数、単一の画像を完成の根拠にはしない。紹介動画は、実際のゲームと旅程の完成後に撮影する。
