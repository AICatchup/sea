# V45 — 乾いた浜へ沖の波を直接注入しない

崖下に張り付く高い白い水膜の原因として、浅水計算の初期状態・境界条件が、描画と異なる波を使っていた。描画は水深・遮蔽による波の変形を使う一方、計算への入力は沖のFFT高さと変位をそのまま適用していた。その結果、乾いた砂浜にも水を直接作っていた。

初期化と境界の波に、描画と同じ水深・遮蔽・水平変位の計算を適用した。海岸へ上がる水はその後の浅水流から生じる。計算済みの遡上水面を水深倍率で潰す変更ではない。沖のスペクトル・風・うねり設定・地形・移動の床は保持している。

## 数値と実行の確認

- 実GPUの8条件で旧/新の入射条件を比較。地面+0.8m・沖の波高位置+1.4mの統制例では、旧処理が水深0.6mを直接生成し、新処理は0。浅瀬と入り江は既存描画の倍率に一致し、外海の波は保持する。方向の8条件も確認し、合計16条件で非有限値0、期待値との差は0.000003未満。
- 同じ新島の浜・カメラ・高画質・昼・風12/swell1.25・開始34秒で、0/5/10/15/20秒を旧/新比較。実時間積分の終端は数十ms異なり、完全な画素同時刻比較ではない。
- 修正後も20秒間に飛沫572・泡224の出生を確認。静止した水面へ置き換えてはいない。浅水計算の時間取り落とし0。
- 全382テスト、型検査、Vite・単体HTMLのbuildが通過。
- 浜→歩行→水泳→潜水→浮上→帰浜を55秒の通常controller入力で確認。301時点、終了時接地、地面から目の高さ1.64m、酸素1。開始地点はQA配置で、OSの物理キーによる全旅ではない。
- 配布HTMLを静的HTTPで実行。開発QAなし、実測384万標本・通常泡の流速取得576地点を保持、外部素材要求0・console error0。file://は未確認。

独立レビューは5秒・20秒の新旧4枚を実視認し限定採用可。高い水膜と浜上の角張った水片が減り、20秒時点には波の盛り上がり・遡上・泡が残ることを確認した。静止画だけで時間方向の自然さや流体モデル全般の正当性を承認したものではない。

**残差:** 大きく平面的な泡の模様、硬い輪郭、灰色がかった海面の帯。砕波の立体感・全体の実写品質は未達。
