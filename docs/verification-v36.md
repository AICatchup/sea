# V36 — 一人称の視点と操作設定

2026-10-07。右へのマウス移動が左向きのyawに変換されていた不具合を修正した。画面右上の「操作」またはOから、感度0.2〜3倍・左右/上下反転・各操作2枠のキー割り当てを変更できる。Mで地図を開閉する。標準への復元と、ブラウザへの自動保存も備える。

## 操作と入力の整合

- 視点のドラッグとpointer lockは同じ感度・反転設定を使う。正のyawは実カメラの右向きに一致する。
- 歩行・泳ぎ・潜降・走行・調べる/乗降・地図・ノート・波の一時停止・画面表示・操作設定が同じ割り当てを参照する。HUD、調査の案内、操船説明も追従する。
- キー重複・最後の1キーの解除・ブラウザ予約キーを拒否する。Ctrlを潜降に使う旧仕様はCtrl+W等と衝突するため、潜降はCを標準としCtrl/Alt/Commandをゲーム用に割り当てない。Shiftは左右共通。
- 地図・ノート・操作設定を開くと押下状態とpointer lockを解除し、移動・航海・酸素・レースの時間を止める。閉じても古い入力が残らない。波の描画は独立。
- 没入表示からM/Jを押した直後、非表示UIのinert解除を待って地図/ノートを開く。実画面で見つけた初回不発を修正した。
- 通常時は専用キー `sea.controls.v1` に保存。壊れた値・未知の版・重複キーは標準へ復帰し、保存が拒否されても現在の画面で利用できる。`capture=1` の開発確認はユーザーの設定を保存しない。
