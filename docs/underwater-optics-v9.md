# Underwater optics v9

実画像 `secret-after-real-dive.png` と `reef.png` を view_image で確認した。前者には水面下面と海底の間に明るいシアン帯があり、後者も左上で同様の帯が見える。公式 diving page4 の写真も参照した。

## コードで確認した原因候補

水面頂点はカメラからの水平距離の二乗 / (2 * 地球半径) を下げるが、合成は水中距離を別の水平 y=0 平面との交点へ短縮していた。有限メッシュの外で sky が背景になる画素にもこの短縮が適用されるため、水面深度の存在しない明るい空を短い水中距離で透過できる。さらに距離85mの上限は青の透過を exp(-.012*85)=約36%で止めていた。これは遠距離背景が消えない独立した数値原因である。実画像の画素がどのパスを経たかはGPU readbackなしでは未確定。

## 修正

選択された実際の水面または不透明物の深度を終端として、投影深度を視線方向の距離へ変換する。水平面交点による短縮と85m打ち切りを廃止。背景depth=1はfarまでの水中減衰となる。ボリュームの照明採取だけ500m以内に限定し、カメラ側透過を各区間で解析積分することで長距離rayの近傍散乱の取りこぼしを防ぐ。水面光学法線に既存の地球曲率の傾斜を加える。波形、地形サンプル、depth occlusion、IOR1.333と全反射の式は保持する。

## 検証と限界

数値テストは視線距離、負距離、近距離連続性、エネルギー境界、Beer-Lambert積則、遠距離減衰を検査する。TypeScript検査はGLSLコンパイルを保証しない。水面下面の反射は引き続き水中放射の近似で、反射された海底形状のray tracingは行っていない。

rootの実機ブラウザで day high、x5930 z-923.918 cameraY-1.373 の同じ向きから比較する。歩行→泳ぎ→潜水の経路、正面・上向きSnell window・下向き海底、浅い岸際とreef、出水直後を確認する。帯の消失だけでなく遠距離の滑らかな収束、近くの魚・海底のコントラスト、GLSL console error、深度遮蔽と水面境界の連続性を確認して初めて描画合格とする。
