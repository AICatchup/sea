## 計測の方法と制約
- `?capture=1` で `frame()` を同期的に呼び、640×360 に縮小した PNG を比較した。経路は、新島の沖の東から西（7600→6150、目の高さ3m）、泊の東の丘の松（90,70→-30,30）、泊北側の岩（-117,-40→-185）。
- 判定方法：各歩で24段階を超えて変化した画素のうち、ON でだけ変化したものと OFF でだけ変化したものを数えて比べた。左右対称なら、LOD による切り替わりではなく、同じ視点移動に伴う通常の変化だけと判断できる。
- 松の経路の7歩目で、ON のフレームが1枚だけ真っ黒に保存された（キャプチャの不具合）ため、その歩は除外した。
- 内蔵ブラウザのペインが非表示で requestAnimationFrame が止まるため、実時間の FPS と、手で操作したときの乗船・移動はまだ確認していない。V64 と同じく、実際の画面での最終確認は主担当に任せる。

## 追加：体の作り直し（`?body=makehuman`、既定 OFF）

依頼「体を丸ごと作り直す」に対応した。見た目の体を、CC0 の MakeHuman の人体メッシュに置き換えた。骨格（47本の骨）、静止姿勢、目の位置、IK、操舵と釣りの手の接触は、既存の `FirstPersonBody` のものをそのまま使う。ブランチは `claude/v65-makehuman-body`（`claude/v65-all` に統合済み）。

| 項目 | 内容 | 証拠 |
|---|---|---|
| 素材の出所 | MakeHuman の system assets（CC0。肌 `young_asian_male`、眼球、眉、まつげ）を、MPFB 2.0.17（Blender 5.1.2）で生成した。MPFB はビルドにだけ使い、そのコードは配布物に含まれない。テクスチャの画素は変更していない | `THIRD_PARTY_NOTICES.md`、`src/assets/player/makehuman-v65/README.md`、json 内の sha256 |
| 再現の手順 | `blender -b --python scripts/build-makehuman-body.py -- <out>` を実行する。頭頂の高さを1.748mに合わせ、game_engine リグを game の静止姿勢に合わせ、関節位置を補正し（最大3.9cm、頭は動かさない）、ウェイトを game の骨に統合する | json 内の `provenance` |

## 追加：モーションキャプチャによる歩き・走り・泳ぎ（`?motion=cmu`、既定 OFF）

依頼「CMU のモーションキャプチャを使って、歩きや泳ぎをもっと人間らしくする」に対応した。実際の人の動きの記録を、既存の骨格（`FirstPersonBody`）にそのまま当てはめた。ブランチは `claude/v65-mocap`（`claude/v65-all` に統合済み）。`?body=makehuman&motion=cmu` と組み合わせて使う想定だが、`?motion=cmu` だけでも従来の体で動く。

| 項目 | 内容 | 証拠 |
|---|---|---|
| データ | CMU Graphics Lab Motion Capture Database から、歩き 35_01〜08（14周期）、走り 35_17〜24（8周期）、平泳ぎ 126_03〜05（22周期）を使った。利用条件は「どんな用途にも無料。製品に含めてよいが、データそのものを売ってはいけない」で、謝辞の記載を求めている | `THIRD_PARTY_NOTICES.md`、`src/assets/player/cmu-mocap-v65/README.md`、json 内の試技ごとの sha256 |
| 変換 | `scripts/bake-cmu-mocap.ts`。各骨の回転だけを移し、骨の長さはゲームのものを使う。CMU の T ポーズは手のひらが下向きなので、腕は親指の向きで合わせた（合わせないと手のひらが上を向く）。安定した周期を切り出して平均し、継ぎ目なくループさせた。何度実行しても同じ sha256 になる | `scripts/cmu-amc.ts`、57KB の json |
| 再生 | walk、run、swim、dive のときだけ、コントローラの `gaitPhase` に合わせて再生する（位相0は左かかとの接地で、足音と一致）。idle、操舵、登り、釣り、サーフィンは従来の手続き生成の動きのままで、idle のときは骨の位置がビット単位で一致する。頭はカメラの向きに固定する | `tests/mocap-gait.test.ts` |
| 足の接地 | 実際の歩行では膝が伸び切らないため、目の高さを固定したままだと足が浮く。踏んでいる足の裏が地面に着くまで体を下げる（走りの空中の局面は残す）。一人称では首だけを伸ばして目をカメラの位置に保つ（目まで下げると、下を向いたときに眼球が見えた）。地面からの足裏の高さは、歩きで手続き生成 −1.1〜3.9cm に対しモーションキャプチャ 0.4〜3.5cm、走りの空中の局面では最大8cm | `mocap-walk-run.jpg`、テスト |
| 泳ぎ | 記録では体が水平に寝ているが、ゲームでは頭を上げて約60°傾けている。その差の80%だけ腕を下げ、腕を伸ばしたときに手が水面のあたりに見えるようにした | `mocap-swim-dive.jpg`、`mocap-first-person.jpg` |
| 走るときの歩数（コントローラの修正） | 走る速さ（4.7m/s）で 342歩/分になっていた（実際の人の約2倍）。`strideRate()` は 1.85m/s 以下では従来と同じ値を返し（歩きの動き・足音・視点の揺れは変わらない）、それより速いときは 179歩/分にした | `5a7117c`、テスト |
