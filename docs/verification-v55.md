# V55 — 大きな接続面の改善と、残る足元の欠損

全体ゴールはACTIVE/UNMET。[構造と失敗した試作](research/sea-continuous-cliff-v55.md)。通常採用、実写相当、全海岸・全旅程、最後の紹介動画は未達。

確認した現物:

- 元LASのSHA256を照合して範囲を再抽出。550,987点/550,909 unique、crop321,237頂点/640,452三角形。観測点の最大高さ106.64mを165mの上端で切っていない。密度除去なし。
- 公開組立CLIを実行し、606,336三角形のrender SHA256 `24739aa1267bb0a2855208e2910d49016f18d289048612ccf244eac79c2639c8` とfootprint SHA256 `71139261d3a047350a0b152003d390a58a7acd772c325129dfec57470382e417` を一致確認。
- 関連70テスト。25件の格子置換/境界変形/投影照会、43件の旧候補・クリッピング・decoder・terrain・solid binding、狭い版と拡張版の実asset各1件。退避した埋設APIの追加テストを現行件数へ含めない。型検査・ビルド成功。
- 拡張版のCPU40rayで最終coast床と実Meshの高さを比較。最大差約7.33e-14m。実Meshへの5身体sweepと水深texelを確認。これは数値整合であり、測量精度や実操作の証拠ではない。
- [採用範囲全域のCPU検証](checks/v55/domain-verification.json):414,399三角形の中心点で欠落0、最終coast床との差0。残存polygonの頂点・辺中点・平均点7,490,356照会で欠落0、実面までの最大距離約4.29µm。全点の閉鎖性・任意の張り出し下の歩行は未証明。
- 実WebGLの8静止視点と[独立レビュー](checks/v55/independent-visual-review.md)。拡張版は次工程用として選択。上側接合と縦カーテンは改善したが、足元の裂け・面の切替・均一な材質が残り、通常採用は却下。

通常のRAF、連続入力、全旅程と音の受入は今回未実施。静止描画でFPS合格を作らない。旧来の最高面床は一般的な3D洞窟/張り出し下を表現しない。参照JPEGの原URL・撮影者は未復元で、現地1cm一致の証拠に使わない。

候補は開発サーバーの明示queryだけで起動し、配布版に候補assetを埋め込まない。海の基準を保ち、岩の形・接合・材質から改善を続ける。
