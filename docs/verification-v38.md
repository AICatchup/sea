# V38 — 船上の視野と泊の水際

船上の標準視野角を62度から78度へ広げ、ホイールで65〜95度に調整できるようにした。操作設定のスライダーと同じ値を保存する。乗降は座席への姿勢変化と実フレーム時間から補間する。独立コードレビューで見つかった「climbからhelmへ変わった途端、視野が狭まる」問題は実controllerの乗降テストを失敗させてから修正した。

wheelはcanvas上で船に乗っている時だけ受け付ける。乗降中・パネル表示中・Ctrl/Meta/Alt/Shift付きは除外。感度やFOVを変更する際に押しっぱなしのWを解除していた設定購読も、キー割り当てが変わった時だけ解除するよう修正した。

## 航空写真に基づく水際

[国土地理院・全国最新写真](https://maps.gsi.go.jp/development/ichiran.html)の[西側タイル](https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/18/232442/104422.jpg)と[東側タイル](https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/18/232443/104422.jpg)を参照。Googleマップ航空写真も閲覧した。写真の泡・濡れ境界から湾曲を近似し、低い砂浜の実heightfieldへ反映した。地理院タイルを参照して作成。撮影日・潮位は未確認なので、測量による海岸線一致とは主張しない。元写真をゲームのテクスチャとして転載していない。

原地形の深さ0.9m以上の水域へ触れる三角形と高地・急な岩は保護。18m以内の低砂浜へ限定し、写真で不確かな西端を局所的に平滑化した。今回実値は17,846頂点、最大変位0.8012m、平均絶対変位0.1647m。水深保護・支持された曲線上の連続性・範囲外不変を実地形サンプラーで検証。通常ON、`strandprofile=0`で旧形状。

水面の格子を増やす別実験では段差が消えず、海岸heightfieldが原因と切り分けた。高密度水面の別実験は採用していない。

## 検証と限界

- 345テスト、型検査、Vite・単体HTMLビルド通過。
- 同じカメラ・時刻34秒・1280×720の5視点で画像比較。独立レビューは湾曲の限定改善として採用可。**西端の三角状接続は残り、全体の実写品質は未達**。
- 通常spawnから歩く→浅瀬→泳ぐ→実船にEで乗る→加速しながらwheel→下船を内蔵ブラウザで実行。歩行は`moveFor`による実controller入力、wheel/W保持は合成DOMイベントで、OSの物理マウス・長押し入力検証とは区別する。
- 実rendererで78→80→95→65度、Ctrl付きwheel無効を確認。W保持中のwheel後も船速が2.63→5.14m/sへ増加。下船後は62度へ復帰。設定画面のスライダー・標準復帰も確認。
- 保存HTMLを静的HTTPから起動。開発QAなし、外部HTTP素材0、console error0。`file://`起動は未確認。
