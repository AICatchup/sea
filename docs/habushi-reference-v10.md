- [令和8年度A3地図](https://niijima-info.jp/cms24/wp-content/uploads/2026/06/niijimaA3MAP.pdf) の情報日付は2026年5月。テキスト上で展望台・漁港・トンネル・ゲート・堀切・各サーフポイントを確認。今回rootでPDF画像の取得はタイムアウトし、画素からの正確な配置を検証したとは扱わない。旧230323村パンフレットURLは404。

## 実際に見た画像と動画

[撮影者の展望台動画](https://www.youtube.com/watch?v=IBkdbO7jFdk) をブラウザで表示し、冒頭の木製展望台の正面、斜面と旧道、反対側からの展望台、細長いコンクリート覆道の近い画面を視認した。木製デッキは高さの違う床と階段・縦桟の手すりを持つ。背後は密な植生で、斜面を道路と開口が反復する覆道が横切る。プレイヤーのシーク表示は0:20、0:35、1:00等へ進めたが、シーク後の画素と時刻の厳密な対応は未校正。動画全編を連続して解析したとは扱わない。元動画・画素を配布アセットへ転用していない。

波については前記録の [2022-03-27撮影動画](https://www.youtube.com/watch?v=RKgTU7eZyWw) の実視認フレームを引き継ぐ。厚い透明な波頭、崩れる白水、風下に流れる飛沫が目標。実測H/T、再生速度、当日の風・潮位は不明で、風14m/s・swell1.3のゲーム比較を現地の再現値とは呼ばない。Googleの白ママの砂浜目線も比較参照で、地図中心を写真の撮影座標と見なさない。
