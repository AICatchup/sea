# V44 — 高く遡上した水の黒い反射境界を修正

強い波が崖下の斜面へ上がると、標高2mの位置に青黒い縁ができていた。水面の形は浅水計算を使っているのに、光を反射する法線だけが標高2m以上で水平なFFT面へ戻る条件が原因だった。その上限を外し、遡上した水にも同じ水面の傾きを使う。

乾いたセルの描画許容差を初めの仮説としたが、実GPUの読み取りでは問題箇所に正の水深があり、主因とは確認できなかった。水位を下げて見えなくする修正は行っていない。

## 確認

- 同じカメラ・高画質・昼・開始時刻34秒から12秒間の波を比較。終端時刻には約5.9ms差があり、完全な同時刻画素比較ではない。
- 地面が2mを超える7画素では、旧法線の反射率が一律約0.994。修正後は水面の傾きに応じ約0.184〜0.494となった。2m未満の対照3画素の差は0.001未満。
- 10画素の水位・地面高の最大差は約0.307mm。この比較差を現地の測量精度とは扱わない。波の時間積分・地形・衝突・移動のコードは変更していない。
- 水際の遷移と干出に関わる9テスト、型検査、Vite・単体HTMLのビルドが通過。V43の全379件を再実行したという意味ではない。
- 独立画像レビューで黒縁の解消を確認し、限定採用可。手前の浅水域・沖の波に明瞭な新しい破綻なし。
- 単体HTMLを静的HTTPで再実行。実測384万標本と通常泡の流速取得を保持し、開発QAなし、外部素材要求0、console error0を確認。

高い水膜の白い帯、鋸歯状の上端、泡の広い模様は残る。今回の黒縁修正と形状・全体の写実品質の達成を区別する。
