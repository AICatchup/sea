# Expanded V55 独立画像レビュー

**最良の次工程用試作は expanded V55。通常デフォルトへの採用は却下（未修正の接合欠陥あり）。** narrow V55より全面的に無欠陥という評価ではない。広い面の連続性は改善する一方、足元の裂けが増えた。

今回 actual expanded の8枚（face / along / close / offshore / south-edge / north-edge / outer-south / outer-north）と rejected-burial を実読した。前回実読済みの narrow V55 6枚、V54 point-stitched 同6枚、baseline3枚と比較した。新しい outer2枚には同姿勢の旧版比較がないため、絶対的な見え方のみ評価する。実ソース・姿勢JSON・FPS・入力・物理は検証していない。ROIの数値、実点数、峰頂座標、4m feather は提供された実装情報であり、この画像レビューによる証明ではない。

## 改善と退行

- expanded-face: narrow右側 x≈990–1080 にあった斜めの接合が消え、右の大壁が連続した。上部の横段も全体として一続きに読める。しかし左下～中央下 x≈60–600、y≈415–510 に白い細長い裂けと黒穴が目立つ。narrowより足元の裂けは増え、ここは退行。
- expanded-along: narrow中央右の壁の切替が弱まり、近景～遠景の壁がつながる。ただし左中段 x≈395–475、y≈300–390 の白黒の裂け、左下寄り x≈150–250、y≈410 の黒片が残る。V54の大量の点・線欠損と縦カーテンよりは明確に良い。
- expanded-close: 主要岩の形は narrow と概ね同じ。前景 y≈565–600 に黒い短線と白い小片が増えた。V54より散在欠陥は大幅に少ないが、narrowに対する明確な品質向上ではない。
- expanded-offshore: narrow/V54では薄かった中央下～左下の岩棚が立体的に続き、露出岩の構成が増えた。これは視認できる違い。右寄り x≈925–970、y≈300–410 の明るい階段状の切替は人工的に見える。上段の非常に規則的な水平テラスは依然支配的。
- expanded-south-edge: narrow中央左の黒い斜め継ぎ目は解消した。壁全体が接続する一方、中央上 x≈775–850 の曲がった縦境界・少数の明るい点と、左下 x≈15–45、y≈370–400 の細い裂けが残る。V54の直線カーテンより良い。
- expanded-north-edge: 岩根元と斜面は概ね連続。narrowより前景 x≈325–475、y≈440 に黒片が増え、影輪郭の一部は角張る。下半分の面は依然ぼやけた同質の斜面。

## 実際の外周

outer-south: 大規模な空洞・縦カーテンは見えない。中央左の丸い大面から右の細い縦溝面へ x≈550–620 で急に性質が変わり、凹んだ境界として読める。左下の小さな白片も残る。接続したことと自然な岩質・形態になったことは別。

outer-north: 右の岩塊と左の斜面は広い範囲でつながり、大規模な黒穴はない。ただし中央の x≈545–670、y≈165–245 の小さな窪み群と、x≈690–815 の細長い谷が単調な斜面の中に切り込まれたように見える。自然な浸食として説得力を増す余地がある。画像だけから外周が完全閉鎖しているとは言えない。

rejected-burial: 左下～中央下、右端に大きく白い鋸歯状の欠けが発生。expanded-faceより明らかに悪く、採用不可。復元版の比較材料であり、現行 expanded がこの状態だとは扱わない。

## 3つの優先順位

1. **足元の裂けを直す。** expanded-face左下～中央下、along左中段、close前景、north-edge前景。広い面の連続性を保ったまま欠損をなくす。rejected-burialの大きな欠けを生む処理へ戻さない。
2. **外周・上側の形態境界を直す。** south-edge中央上 / outer-south中央の曲がった面境界、offshore右寄りの階段状切替、outer-northの窪み群。旧narrowの境界が消えても、新しい境界が自然に読めるかを同8視点で確認する。
3. **岩・砂と地質の説得力を上げる。** close大岩、outer-north斜面、offshore上段。均一な灰青材料、丸すぎる大面、規則的テラスに対し、風化・破断・粒度と材料差を形状に沿わせる。
