# V57 独立した見た目のレビュー

別の担当が旧V56のhelm・到着画像と、新しい正面・下向き・左右・操船中・後方の6画像を実際に閲覧した。数学検査の結果はレビュー前に知らせていない。同時刻固定のA/Bではない。

判定: **操船時の握り改善として限定採用**。

- 旧版では開いた指と掌が輪の外側に浮き、支えている印象だった。今回の正面・下向きは掌が縁に寄り、指が内側へ回るため、握っていると読める。
- 左右・操船中でも接触が維持される。明白な大きな隙間・貫通は見つからないが、暗い重なりやUIの遮蔽があり、微小な貫通の不存在までは画像から判定できない。
- 腕は太く、肘から肩の形が硬い。旧版にもあったため、今回の握り改善を拒否する新しい差分とは判断しない。
- 後方では黒い上半身・肩と首の突起が大きく映る。旧stored-rod画像にも同様の課題があり、今回初発とはいえない。角度固定A/Bではないため増減は断定しない。

全体の実写品質、現地再現、性能、ゲーム完成への承認は含めない。後方身体と腕の造形は引き続き改善する。
