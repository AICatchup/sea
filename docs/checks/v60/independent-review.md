# 独立確認 — V60

同じ担当がread-onlyでコードと実画像を確認。初回の測定地形込み4視点では、植生は改善候補だが地形の水平帯・壁脚・暗い平板状の葉を課題として指摘。

コード確認では、nearで配置した幹をfarの基部で衝突判定していた差（variant0 6.5cm、variant1 3.4cm、variant2 23.3cm）と、surveycanopy+crownの二重配置を指摘。near基部へ統一し、実native GLBを読むテストでfar幹を意図的にずらしてもproxyが動かないことを確認。surveyを優先し重複を除いた。alphaのvariant別routingも修正（現行3PNGは同一bytes）。

最終コードは予算を現在LODとの差分で計算し、near昇格後のmid/farカウンター重複を除去している。別担当による関連7件成功。同じ旧地形のbefore.pngとdefault-final.pngで、中央・左側の樹冠の葉と枝が増えた。浮遊や接続切れはこの画像範囲では見つからず、植生のみ採用を受入。

改善は控えめ。丸い岩、白く滑らかな壁脚、暗い葉が残る。全体の写実品質、現地への忠実度、全旅程の受入ではない。FPSはrootの実測で、この画像レビューからは証明しない。
