# 羽伏浦全岸・白水の検証 V7

目標は継続中です。実写同等には達していません。独立レビューでも、岩壁の規則的な縦面・帯、滑らかな崖裾、大きく巻く砕波の不足が残ると判断しています。

## 実景と地理

国土地理院2018年火山基本図の実際のSHP/DBF/PRJを取得・読解。JGD2011平面直角IX系、Easting/Northing、海岸線コード5106を確認しました。東海岸候補はGRS80測地線で6,727.291m。ただし「最南緯度の点から北側の線端」という幾何定義で、名称付き羽伏浦の確定長・現在の汀線長ではありません。記録は2015/2016年、公開は2018年です。[公式配布](https://web1.gsi.go.jp/bousaichiri/vbm-data_kanto_chubu.html)

候補南端が従来の細分地形より約449m南へ出ていることを確認し、南部の標高データと地形を追加しました。独立反証で、HTTP200のDEM5Aタイル内の欠損画素を海と見なしていた問題を発見。3地点は5A欠損・5Bなしでも10Bに2.27/3.36/3.16mの有効標高がありました。画素ごとの有効5A→5B→10B補完へ修正し、5,757画素を補完。旧範囲外の歴史海岸線60点は全て新範囲内、地形高1.99〜3.58mになりました。これは陸地標高の欠損修正で、潮位に一致した海岸線測量の証拠ではありません。残存欠損への海底は引き続き推定です。[欠損値の公式仕様](https://maps.gsi.go.jp/development/demtile.html)

Googleマップの実航空写真、2024年5月の白ママ砂浜写真、メインゲートの実景を参照。Allen Moriの羽伏浦動画を追加観察し、4:34〜4:35の透明な青緑の波面、厚く巻く波頭、飛沫と白水への崩れを確認しました。サーファーとの相対関係は見えるが、体格・編集・再生速度・気象が不明なので実波高や周期を数値測定したとはしません。[原動画](https://www.youtube.com/watch?v=RKgTU7eZyWw)

## 描画と動作

白水は固定pool1024片、追加1draw/2048tri、既存576点/2304BのFFTサンプルを共有します。波の振幅制限で除いたエネルギーを、実際の未制限crestと対照して観測する処理を追加しました。高さの2倍を波高とする対称波の近似、固定gamma=.73、既存cap損失との小さい方です。水面の変位・位相・人/船の高さ計算は変えていません。CFD、波の巻き込み、実測波高の再現ではありません。[式・制約](./shore-breaker-dissipation-v7.md)

GPU検証でGLSL予約語のコンパイル失敗を発見して修正。さらに、水面の後に白水を描くpassと、岩・地形・体への深度判定を接続しました。泡の頂点も現在のFFTへ追従します。風14m/s・うねり1.3という検証条件で、12秒後に白水約350片と飛沫を観察しました。値はモデル条件で、動画の気象の測定値ではありません。数字だけで写実性の達成とはしません。

既存CC0 Sand 02の実寸2.14mの写真PBRを借用し、低く平らな砂面へ限定して濡れた暗さ、粒の濃淡、粗さと法線を加えました。原写真の茶色は中立化し、岩壁全体へ砂を貼りません。現地の砂を計測した素材ではありません。所有者はIslandWorld、材質は借用し二重disposeしません。

scarp=1の急崖は共有高さ場による方向性の実験で、既定へ昇格していません。追加近距離gridを含め10mesh/約261万tri。独立CPU検証では親との境界差最大3.8µm、可視三角形と足元sampler差最大2.06mm。ただし形状最大変位約55.7mは作者による推定で、実測・写実性の合格を示しません。
