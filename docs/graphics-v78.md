# V78 — 台風うねりの砕波

新島の大きなうねりを確認するため、海の表情に「台風うねり」を追加。風16、うねり1.8の描画条件で、厚い波頭、落下、着水時の白水、残る泡を実装した。実測の波高や周期を再現したとの主張ではない。

## 変更

- 局所的な波頭と波面の高低差に応じて、落下する水の厚みを増やす。内外面と端面を持つ閉じた形状にした。
- 落下端の前方移動を抑え、支持が消える際は水平距離も縮める。水面の下に入った面を描画しない。
- 水中へ向かう屈折光を薄膜の光路長へ切り詰めず、海底の砂が波頭へそのまま透ける問題を抑える。
- 大きな落差の着水では白水が膨らんでから落ち着く。白水の分割数を増やし、急な水面変位による引き伸ばしを制限。
- 台風うねりでも昼の写真ベースの空を使用。空の非同期ロード後も選択を維持。

## 実行確認

- 関連117テスト合格。型検査、Vite、単体HTMLビルド成功。
- Chromeで録画。18秒の確認区間に計算時間も0→6.016→12.033→18.049秒と進行した。背面タブによる時間抑制を除外。
- 海面履歴は有限値、WebGLエラー0。プログラム一覧は空だったため、それをリンク成功の証明には使用しない。
- GIFは238フレーム、15.87秒、236個の異なるフレーム、無限ループ。MP4も保存。
- 白水の通常層の最大三角形数は30,720から122,880へ増加。描画回数と読戻しは維持。速度改善を主張しない。

## 残る差

近距離の巻き込み端には硬い輪郭や反射の帯が残る。白水も3D流体計算そのものではなく、生成・移流・減衰する近似表現。実写同等、台風の特定映像との一致、全視点での完成とはしていない。
