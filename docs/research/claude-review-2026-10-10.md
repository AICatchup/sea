## 採用を提案する変更: 実測地形のLOD（`51b3cd9`）

新島の25cm実測パッチ（7,672,002三角形、247チャンク）は、距離に関係なく全解像度で通常・反射・影の各パスに描かれていた。泊から新島の方向を向くと、1フレームの最大三角形数は約5,500万だった。

- 各チャンク（128セル）に、同じ頂点を使う粗い index 範囲（間隔2〜64）を追加した。外周は元の境界頂点をすべて保つので、隣のチャンクとレベルが違っても継ぎ目は元と同じで、隙間は出ない。
- 描画カメラごとに、投影したセル間隔が4px以下で、かつ事前計算した高さ誤差が1px以下になる最も粗いレベルを選ぶ。粗くする方向には20%の余裕を設けて、閾値付近でのちらつきを防ぐ。急な崖は平地よりずっと遠くまで元の解像度のままになる。影のパスは直前の透視カメラの選択を使う。
- 高さの照会（`surfaceHeightAt`）、描画前のレイキャスト、内部の置換、足跡のハッシュは、引き続き元の三角形だけを使う。置換されたチャンクは元の解像度に固定される。
- `?terrainlod=0` で従来の全解像度描画に戻せるので、同じビルドで比較できる。

| 計測（RX 7600 XT、1280×720、高品質、同じビルド） | 従来 | LOD |
|---|---|---|
| 泊から新島方向、新島パッチの描画三角形数 | 7,672,002 | 200,426 |
| 同じ視点、フレームの最大三角形数 | 55.4M | 40.3M |
| 同じ視点、フレームの平均三角形数 | 33.7M | 23.8M |

見た目: 新島の近い崖と沖からの静止画で、全解像度との平均画素差は 0.05 と 0.17（255段階中）。高さ誤差を考慮する前の版では崖に縦の筋が出ていたので、誤差基準を入れた。

テスト: `tests/measured-grid-lod.test.ts`（継ぎ目、面積、巻き方向、距離と崖による選択、置換時の固定）を追加した。`tests/tomari-survey.test.ts` は index の末尾にLODの範囲が加わったため、元の描画範囲の中だけを見るように直した。最終状態で tsc と全509件のテストが合格。

## まだ大きい負荷（未変更、Codex への提案）

泊から新島の方向を向いた1フレームの内訳（全パス合計）は、松 8.9M、写真計測の岩 4.6M、新島の地形（パッチ以外）3.6M、海の生き物 3.2M。

1. **松の far LOD**: 約1,000本が1本約5,000三角形の far で描かれている。`distant`（約2,000）を使う距離を短くするか、ビルボードに置き換えると、数百万単位で減る。`foliage-lod.ts` は Codex が編集中なので変更していない。
2. **写真計測の岩**（`Photo-scanned cliff outcrops *`）: 100個のインスタンスが、距離に関係なく全詳細（boulder_01 は main パスだけで約1.1M）で描かれている。
3. **反射パス**: 0.42倍の解像度だが、通常パスとほぼ同じ三角形数（約14〜16M）を3フレームに1回描いている。反射用カメラだけ LOD を粗くする余地がある。なお、three の Reflector は斜めの near 面で水面の反対側をすでに視錐台カリングしているので、水面より下の物体を手動で隠しても効果はない（実測で確認済み）。

## 作業環境: ディスク容量

2026-10-10 に C ドライブの空きが 0.29GB まで減っていた。`outputs/releases` は1版あたり約1GB（`SEA-source.zip` 約650MB と `SEA.html` 約300MB）で、ほぼ毎時間増えていた。ユーザーの承認を得て、v3〜v55 を `F:\sea-archive\releases` へ移動した（削除はしていない）。

- 移動中に新しく作られた v60 も一度移動されてしまったが、すぐに元の場所へ戻し、`SHA256SUMS.txt` のハッシュが一致することを確認した。
- 提案: ソースは git の履歴にあるので、各版の `SEA-source.zip` は最新の数版だけを残す。古い版は F ドライブへ移す。

## 検証の制約

内蔵ブラウザのペインが非表示のときは requestAnimationFrame が止まり、通常のループでの FPS や移動は計測できない。今回の数値は、同じビルドで `frame()` を同期的に呼んで計測した三角形数で、FPS ではない。非表示中に水中の視点へ切り替えると、非同期の GPU 読み戻しが進まず画面が壊れたが、これは計測方法によるもので、ゲームの不具合とは確認していない。
