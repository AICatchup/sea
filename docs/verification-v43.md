# V43 — 沖の波向きと通常プレイの引き波をつなぐ

沖の波と浅瀬の流れが別々の向きを使い、通常プレイの泡は常に岸へ進む実装だった。沖のFFT波が持つ主な進行方向を浅瀬の境界へ渡し、泡は計算された水流に乗って岸・沖・沿岸へ動くようにした。

## 変更と根拠

FFTの正の時間位相と逆変換の符号を確認し、スペクトルの軸と実際の進行方向を共通定義にした。平坦な浅瀬でも流量がゼロにならず、浅くなるにつれて入射波を岸の法線へ曲げる。これは12mを接続深さとする局所的な浅水近似で、実測波向きや全周波数の屈折計算ではない。[TxDOTの波の解説](https://www.txdot.gov/manuals/des/hyd/chapter-15--coastal-hydraulic-design/section-4--waves---currents/waves.html)に示される浅水変形・屈折の区別に沿っている。

通常の薄い泡にも、3D泡候補だけが使っていた浅水流速の取得を接続した。取得は既存の1要求へまとめたまま、5Hz・576地点・4,608bytes。泡は符号付き流速へ滑らかに追従し、水流の取得が一時的に失われても出生地点へ跳ね戻らない。移動先が乾いた地面なら消す。地形・歩行の床を見た目だけで動かしてはいない。

## 実行確認

- 全379テスト、型検査、Vite・単体HTMLのビルドが通過。
- 実際のGPU初期化シェーダーを平坦床・東向き斜面・斜め斜面・沖向きの4条件で旧/新比較。8ケースで非有限値0、期待流量との差は最大約0.00000314。平坦床の流量ゼロが解消した。
- 新島の同じ浜で20秒間、通常の泡と実GPU由来の水流を追跡。105時点・2,796個の有効観測、39個の同一粒子で岸向き/沖向きの流速反転を記録。計算された流れの証拠であり、現地観測ではない。
- 20.04秒の浅水計算で時間の取り落とし0。これは今回の実行速度での確認で、低fps全条件の保証ではない。
- 北側の浜から55秒間、歩行→水泳→潜水→浮上→上陸を通常controller入力で連続実行。302時点、終了時に接地・地面から目の高さ1.64mを確認。開始地点はQA配置で、OSの物理キーによる全旅の検証とは区別する。
- 正面5枚・海岸沿いの新旧画像を独立目視し、今回による明確な新規悪化は見られず限定採用可。静止画レビューを移流精度の証明としていない。
- 配布HTMLを内蔵ブラウザの静的HTTPで起動し、通常の泡が576地点の流れを取得、開発QAなし、外部素材要求0、console error0。file://起動は未確認。

## 採用しなかった候補と残差

立体泡も比較したが、厚い白板・氷状の破片に見えるため通常版へ採用しなかった。小型化・短寿命化・法線改善の試作と画像は作業用成果として保持している。

通常版にも広い白い塗り模様、崖際の高い水膜と黒い縁が残る。海岸沿いの旧/新比較で後者は旧方向処理でも確認でき、今回の修正で解消したと扱わない。立体的な砕波、漂砂・崖の侵食、全体の実写品質は引き続き未達。[海岸形成の根拠と残作業](habushi-coastal-processes.md)。
