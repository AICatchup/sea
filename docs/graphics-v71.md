# V71 — 泊東側の地形と紹介画像

2026-10-13。全体の実写品質は未達。今回の採用範囲は東側の岩場、水際の接続修正、実行画像とREADMEの更新です。

## 地形の変更

東京都デジタルツイン実現プロジェクトの25cm GeoTIFF、09QC1546と09QC1547を元の格子で結合してからゲーム座標へ変換。東側の513×513格子を通常表示へ採用しました。表示、足元、水深の判定は同じ面を使用します。元データ・変換・ハッシュは `src/world/tomari-east-survey.generated.ts`、再生成は `scripts/build-tomari-east-survey.py` に保存しています。

- 元の正標高を海底と混ぜる際、水際の段差が増幅される処理を修正。
- 高さ1m以上の陸地から離れた低い湿潤域は、距離2〜6mで信頼度を落とす加工を追加。不確かな孤立値が板状の突起になるのを抑制。
- この信頼度は制作上の推定です。点群の分類結果や実測の海底ではありません。
- 25cmは格子間隔。格納単位の1cmは現地精度ではありません。張り出しや洞窟は標高面だけでは再現できません。

出典: [東京都・島しょ地域点群データ](https://www.geospatial.jp/ckan/dataset/tokyopc-shima-2023)、CC BY 4.0。東京都のデータを加工して作成。東京都による承認を示すものではありません。
