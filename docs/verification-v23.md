## 実景から確認した差

[式根島観光協会の泊海水浴場](https://shikinejima.tokyo/play/beach/tomari_beach/)を開き直し、既存の泊の実景参照写真を実表示して現在の画面と比較した。写真は青く透明な浅瀬、粗い岩肌、密な植生が目立つ。ゲームの崖はまだ滑らかで、樹冠も薄い。撮影時刻・露出・撮影位置が同一ではないため、写真との画素一致や測量済みの再現とは扱わない。保護された実景写真の画素はリポジトリに追加していない。

## 今回の修正

- 林床の巨大な緑の葉写真を、既存の実寸2.14mのCC0写真素材による土・落葉へ変更。落葉の強い黄土色を抑え、世界座標に固定した土・苔の色の変化にした。現地の反射率や苔の分布を測ったものではなく、色の調整は作者の判断。
- 岩壁の追加スキンを非表示にした同じ視点との比較で、大きな三角形／V字形状がスキンの境界から生じると確認。2.4mの境界帯で凹凸を弱め、境界の頂点を元の面から4.5cm内側へ収めた。表裏と閉じた境界を保持し、既存の角接触の分離も維持した。
- スキンの形が緩斜面になった部分へ草や砂の色が貼られる問題を修正。岩専用の材質が元の岩PBRテクスチャと湿潤表現を共有し、土／草／砂の傾斜判定を適用しない。素材を共有する場合の解放と、光の処理を二重に追加しないことも検証した。
- 接続スキンを基礎地形の変更と切り離した。通常では林床と接続スキンを採用し、以前の `coastform` による大形状変更は引き続き候補扱い。地形・水深・初期位置・島の到着地点は今回のスキン採用では変更していない。

通常の `ground` と `cliffskin` は有効。開発用の `?ground=0&cliffskin=0` で旧経路と比較できる。通常UIにモード切替や瞬間移動は増やしていない。`coastform`、`originaltree`、`crown`、`leafvolume`、幾何ベースの屈折候補は今回採用していない。
