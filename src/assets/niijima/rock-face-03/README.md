# Niijima cliff detail V40

Original **Rock Face 03** by **Dario Barresi** (photography) and **Rico Cilliers** (processing), from [Poly Haven](https://polyhaven.com/a/rock_face_03), licensed [CC0-1.0](https://polyhaven.com/license). These files are unchanged provider originals; manifest.json records source URLs, API MD5, local SHA-256, dimensions and bytes.

The photographed tile covers 2.7 × 2.7 metres. Albedo is sRGB; OpenGL normal and ARM are linear data. Runtime metalness remains zero. The shader neutralizes brown albedo using its measured mean linear luminance 0.16029633 and preserves local luminance, AO, roughness and normal response. Thin ash beds and physical erosion relief are authored, not measured from this unrelated scan. Repeating texture coordinates are fixed in world metres, never to the camera.

**This is an analogue material photographed elsewhere, not a scan of Niijima or evidence of local geology.** GSI determines the large landform. Niijima tourism and Google images are observation references, not included textures. Actual-site Commons photographs were inspected separately; they are not bundled with this material.

The owning NiijimaCoast loads/disposes these maps. Its material is borrowed by the closed cliff meshes. Source bytes are preserved. The lower loose talus receives weaker erosion and detail; exposed steep faces receive the layered response. Missing texture loads retain the generated/procedural fallback. Visual comparison, relighting, collision and runtime performance remain separate checks.
