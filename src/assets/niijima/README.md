# Generated Niijima pumice material V9

`pumice-albedo-generated-v9.png` is a synthetic diffuse surface asset made with the built-in ImageGen tool on 2026-10-01. The tool did not report a model identity. The image contains no Google Maps pixels and is not a field photograph, scan, measured heightmap, or measured PBR material of Niijima.

The prompt requested a flat orthographic pale volcanic pumice/tuff surface with irregular pores, grains and subtle discontinuous ash bedding, nominally a2m tile. The world scale is authored. Current measured mean linear RGB is0.58451/0.53945/0.49247. The image may retain microscopic lighting; it is used only for diffuse variation and does not establish physical normal/roughness data. Source image1254×1254, SHA2568e51ca2f71411648aea362845c51228f0e948381e453bb0f6dc4c25a480ec991.

The runtime uses world-space triplanar projections on sloping rock surfaces. Sand and low flat beach remain separate. The texture is owned/disposed by NiijimaCoast, while the scarp material borrows the same closure. Original generated output is retained outside the project; the consuming asset is copied into this project. Multiview quality remains a separate acceptance test.
