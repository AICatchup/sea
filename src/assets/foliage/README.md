# Tomari foliage atlas

`tomari-black-pine-v1.png` was created with the built-in Imagegen tool for this project, with actual alpha transparency. It is an authored photographic texture rather than a surveyed plant or a crop from the Google reference photo.

Prompt: A 2 by 2 transparent atlas of Japanese coastal black-pine branch needle clusters (top two quadrants) and small glossy evergreen shrub twigs (bottom two), sharp photographic botanical cutouts, neutral diffuse daylight, irregular branching and open leaf/needle spaces, generous transparent gutters, no baked shadows, environment, text, labels, pots, or grid lines.

The geometry uses crossed cards with cutout depth writes and alpha-tested shadows, together with explicit trunks, roots and lateral branches. These cards approximate foliage volume; they are not individual volumetric needles.
