# CC0 coastal foliage LOD candidate

Official Poly Haven assets: [Pine Sapling Small](https://polyhaven.com/a/pine_sapling_small) and [Shrub 02](https://polyhaven.com/a/shrub_02), CC0 1.0. `provenance.json` binds original URLs, original API MD5, byte lengths, SHA256, physical bounds, derived bounds, reduction errors, and bundled GLB hashes. Runtime loads bundled files only. No Google photo pixels are included.

The pine source contains three distinct modeled stems and individual three-dimensional needles. An offline continuous deformation applies to both branches and needles, raising the branch collar and spreading/compressing the crown into a broad asymmetric coastal profile. These are authored adaptations of a small pine, not surveyed Japanese black pines. The shrubs retain three distinct all-angle plant meshes with individual leaves. Original 1K diffuse, OpenGL normal and ARM JPEG bytes are embedded once per asset and shared between LODs. Rough diffuse shading, normal mapping and a small shadow-attenuated backlighting approximation are used for thin foliage; GPU verification of this lighting is pending.

Near pine variants have 16,477 / 16,522 / 16,506 triangles; middle pine variants have 2,440 / 2,439 / 2,440. Near shrub variants have 2,299 / 2,297 / 2,293; middle shrub variants have 420 / 416 / 434. Far geometry is an authored 3D crown proxy with no camera-facing planes (84 triangles per pine, 24 per shrub). The legacy `pines`, `shrubs`, `bark`, `leaves` API stays available for the island forest.

AssetWorld keeps its existing 3,403 pine and 11,089 shrub transforms, with no count increase. User pines join the same pools. Each transform belongs to exactly one band. At most 40 near pines within 42m and 72 middle pines within 115m are rendered; shrubs use 36 near within 21m and 120 middle within 63m. Nearest overflow goes to the middle band. The worst possible near triangle cost is 743,644. Detailed near models cast shadows; middle and far models avoid distant shadow-map load. The active foliage needs at most 24 draws, 12 more than the previous field, and the two bundled GLBs total 9,240,680 bytes.

CPU measured triangle costs on the pre-integration ground: shore 1,375,269 (609,162 near), cliff 1,508,052 (742,700 near), lookout 1,508,017 (742,698 near), distant 551,988 (no near). These counts are geometry submitted before view frustum/occlusion, not GPU time. Terrain changes can change placement acceptance and resulting totals.

`pnpm test`: 29/29 passed. `pnpm build`: type check, production build, standalone HTML passed. CPU validation checked all GLB positions/UVs/normals for finiteness, unit normals, zero degenerate triangles, mutually exclusive LOD totals, 96 placement capacity, one-step undo, vessel transform preservation, single disposal of owned resources, and source-scan ownership during rock placement hydration. CPU checks do not load image pixels or compile shaders; GPU, multiview appearance, exact transitions, photography match and human acceptance remain unverified.
