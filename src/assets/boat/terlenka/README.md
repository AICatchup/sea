# Terlenka — Poly Haven CC0 photographed fabric

Source: https://polyhaven.com/a/terlenka
License: CC0-1.0, https://polyhaven.com/license
Photography: colormass. Processing: Rico Cilliers.

The diffuse, OpenGL normal and roughness JPEG files are unchanged 2K downloads.
Original URLs, sizes, MD5 and SHA256 are in receipt.json; API info/files are preserved.
Dimensions [265.70814767607123,266.2999927997589] are millimetres, according to
https://github.com/Poly-Haven/Public-API/blob/master/swagger.yml (texture.dimensions).

SEA uses vessel-local metre-scale UVs with a 0.265708 × 0.266300 m repeat.
The source is a polyester textile, used as an authored material choice for the
fictional boat cushions. It is not a measured match to a photographed Japanese vessel.
The material is a comparison candidate until runtime visual review; see boatcloth=1.
The game uses bundled local files and does not query the live Poly Haven API.
