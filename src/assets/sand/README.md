# Photographic sand material

This is the unchanged original 2K **Sand 02** PBR set by **Charlotte Baglioni**, supplied by [Poly Haven](https://polyhaven.com/a/sand_02) under [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/). [Poly Haven's asset license](https://polyhaven.com/license) permits use and redistribution. The source is a real coastal sand scan; it is a material reference, not a survey or photograph of Tomari itself.

`manifest.json` binds each source download URL to its official API MD5, local SHA-256, byte size and JPEG frame header. All three maps are 2048 × 2048, 8-bit RGB. They total **12,192,138 bytes**. The official 2K JPEG files were used so the original map set remains below the 25,000,000-byte import limit; original 2K PNG normal plus albedo/ARM would exceed it. No file was resized, recolored, cropped, packed into an atlas or recompressed.

- `sand_02_diff_2k.jpg`: photographed albedo; load as sRGB.
- `sand_02_nor_gl_2k.jpg`: OpenGL tangent-space +Y normal; load as linear data.
- `sand_02_arm_2k.jpg`: ambient occlusion in R, roughness in G, metalness in B; load as linear data. The shader should treat sand as nonmetallic.

The [official metadata](https://api.polyhaven.com/info/sand_02) reports a **2140 × 2140 mm** scan. Millimeters are defined in the [official API schema](https://github.com/Poly-Haven/Public-API/blob/master/swagger.yml). A complete texture tile therefore occupies **2.14m**, with **0.46728972 tiles per world meter** and roughly **1.045mm per 2K texel**. Use the same UVs for albedo, normal and ARM. This preserves fine photographed grains with only occasional larger shell and dark mineral fragments. Reducing the whole tile to fit a detail layer is an artistic change in scale; enlarging it makes the grains appear gravel-sized.

`src/world/sand-material.ts` exports `SAND_TEXTURE_URLS`, `SAND_SURFACE` and `loadSandTextures(anisotropy)`. The loader uses repeat wrapping, trilinear mipmaps and adjustable anisotropy. Its CPU-only placeholders support existing terrain tests; actual image upload must be verified by the integration owner. The terrain owner registers `textures` in its normal resource-disposal list.

For predominantly horizontal sand, sample at `vec2(point.x, -point.z) / 2.14`. With this projection a decoded OpenGL normal maps to world axes as `vec3(n.x, n.z, -n.y)` on a flat upward surface. In the terrain shader, construct the tangent frame from the projected UV derivatives and **view-space surface position/normal**, then multiply the decoded normal through that frame. Three.js's `getTangentFrame` has this behavior when tangent normal mapping is enabled; a custom hook without that define needs its own equivalent derivative frame.

For triplanar sampling, project and decode each normal in its own tangent frame before blending the **view-space normals** with the matching triplanar weights. Use sign-correct UVs on opposite faces. Blending raw tangent-space RGB normals or directly adding them to the terrain normal rotates the relief incorrectly. Use the geometric normal for projection weights, so detail normals cannot feed back into their own blend.

Starting runtime recommendations in `SAND_SURFACE` are normal XY strength 0.60 dry / 0.32 wet, roughness 0.78–0.96 dry / 0.27–0.48 wet, and wet albedo multiplier 0.62. These values are authored display recommendations, not measurements. The original scan is brown-gray and fairly dark. Calibrate Tomari's pale dry color in linear light while retaining its fine luminance/color variation; the downloaded files stay unchanged. Drive wetness from shoreline exposure and wave contact, and blend it continuously. Keep full mipmapping at eye-level grazing angles to control grain shimmer. Use a separate low-frequency modulation for uneven beach coloration rather than increasing the grain tile size.

To reproduce the import, run `node scripts/fetch-sand.mjs`. It requests just this asset's metadata and three pinned files, sends the required application User-Agent, enforces the download limit and preserves existing local texture bytes. To verify locally with no network, run `node scripts/fetch-sand.mjs --verify`. The runtime uses bundled local images and does not call the API.
