# Generated sea sound assets

Generated 2026-10-07 through the connected Runway sound-effect service. The hull-water generation exposed an ElevenLabs backend receipt; subsequent output receipts did not separately expose the backend model. These are synthetic sounds, not field recordings from Shikinejima or Niijima. No voice or personal media was supplied. Provenance records source and prepared hashes without private provider URLs.

Runway permits use of generated content without non-commercial restrictions: https://help.runwayml.com/hc/en-us/articles/21668707517587-Can-I-use-the-content-I-made-in-Runway-for-commercial-purposes

These assets are not labeled CC0. DC offset removal, conservative RMS/peak normalization, a 300 ms overlap for ambient loops, and 30 ms fades for one-shots precede Ogg encoding. Actual game gains depend on local motion and water state; no exact measured acoustic match is claimed.
