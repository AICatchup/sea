# White Plaster 02

Poly Haven, Rob Tuytel, CC0-1.0. Official source: https://polyhaven.com/a/white_plaster_02

Unmodified 2K diffuse, OpenGL normal and ARM JPEGs. Download URLs, source MD5, sizes and local SHA256 are in `manifest.json`. All three size/MD5 readbacks passed. Used as a generic finish on the authored Habushi gate, not a photographic scan of its actual paint. The diffuse variation is calibrated to bounded white-paint reflectance in the shader; raw asset pixels remain unchanged.

The website says 1m wide while official API metadata says 1.5M x 1.5M. Current world mapping follows the API's 1.5m; this is an authored scale choice, not a measured property of the real gate.
