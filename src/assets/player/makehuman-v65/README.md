# MakeHuman diver body (CC0)

Generated by `scripts/build-makehuman-body.py` (Blender 5.1.2, MPFB 2.0.17, MakeHuman system assets CC0, pack sha256 `b542127a…0107`).

- `makehuman-body.bin/json`: body, eyes, eyebrows, eyelashes. Positions are in the game's rest frame (three.js metres, +Y up, -Z forward), skinned to `FirstPersonBody` bones by `name@L|R|C` keys. `json.provenance` records macros, scale, per-bone joint shifts and the eye offset.
- `makehuman-*.png`: unchanged CC0 textures (sha256 in the json).

Rebuild: `blender -b --python scripts/build-makehuman-body.py -- <this folder>` with MPFB installed and the system asset pack extracted into MPFB's user data folder.
