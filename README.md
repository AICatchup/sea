# SEA — どこまでも、海。

風で生まれる波、空の映り込み、波頭の泡、遠い水平線。ブラウザいっぱいに広がる海を、ただ眺めるための体験です。静止画や動画を背景に使わず、海と空をGPUで毎フレーム描画します。

## 開く

完成ビルドの `dist/sea.html` をブラウザで開くだけで動きます。ネット接続やサーバーは不要です。フォントと第三者ライセンスもこのHTMLに含まれています。

WebGL 2と浮動小数点の描画に対応したブラウザ・GPUが必要です。Chrome / Edgeでハードウェアアクセラレーションを有効にしてください。対応しない環境では、その旨を画面に表示します。

## 海の楽しみ方

- **夕凪 / 青い海 / 荒天 / 薄明** — 空、光、水の色、風とうねりを切り替えます。
- **風の強さ / うねり** — 海の表情を調整します。
- **ドラッグ** — 見回します。
- **スクロール / 2本指のピンチ** — 視点の高さを変えます。
- **波の音** — 手続き的に合成する波音をオンにします。音は初めから鳴りません。
- **カメラ** — 操作画面を含まない海のPNGを保存します。
- **没入モード / H** — 操作画面を隠して海を眺めます。
- **ひと休み / Space** — 波の動きを止めます。
- **描画品質** — 自動・高・標準・軽量を選べます。自動では描画速度に合わせて解像度を調整します。

スマートフォン幅では環境パネルを最初から閉じています。動きを減らす設定が有効な場合は、一時停止した状態で開きます。

## 開発とビルド

Node.js 22.13以降、または24系とpnpmを使用します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

```sh
pnpm test
pnpm build
pnpm preview
```

`pnpm build` は型検査、Viteの本番ビルド、単体HTMLの生成を行います。`dist/` は静的ホスティングへ配置できます。相対パスを使っているため、サブディレクトリでも動作します。公開・デプロイは別の操作です。

## 描画の仕組み

Three.js / WebGL 2上で、風の方向と強さを反映した波のスペクトルを時間発展させ、GPUの逆FFTで水面へ戻します。384m・256²と24m・128²の2つの空間スケールを重ね、大きなうねりと細かな風波を作ります。手前が密な放射状のメッシュが、水平線まで広がります。

水面は高さと水平変位、波の傾きから描画します。Fresnel反射、GGXの太陽光反射、水中の散乱を近似した色、波面の圧縮から生まれて減衰する泡、距離に応じた細部のフィルタを組み合わせています。空の光と海霧を揃え、地球の曲率で遠い水面を水平線へつなぎます。最後にFXAAで輪郭を整えます。

流体力学の完全な解や海岸での砕波モデルではなく、開けた海の見た目と動きを作るスペクトル波・光学近似です。実際の海象予測には使いません。

## 検証

`tests/spectrum.test.ts` は、再現可能な波の生成、エネルギー、共役対称性、入力条件を検証します。開発サーバー上の `/tests/gpu.html` は、解析解のある波を使い、GPUの高さと水平変位を照合します。

本番ビルド、ブラウザでの4プリセットと操作、PNG保存、波音、スマートフォン幅、単体HTMLのオフライン起動を確認します。今回の結果と実行環境は `docs/verification.md` に記録しています。画面幅を模擬した確認は、スマートフォン実機での受入確認とは区別しています。
